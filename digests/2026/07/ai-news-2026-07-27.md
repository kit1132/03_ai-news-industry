## モデル・オープンウェイト

### Kimi K3 の重み公開、本日 9:00 JST 予定（最重要）
- Moonshot AI が **2.8兆** パラメータの Kimi K3 の全重みを Hugging Face で公開予定。公開時刻は 7/27 00:00 UTC＝9:00 JST で、本ダイジェスト作成時点（5:06 JST）では未公開。史上最大のオープンウェイト公開となる。ライセンスは Modified MIT で商用利用可。
- MoE 構成（896エキスパート中16のみ発火）・1Mトークン文脈。容量は BF16 で約594GB、MXFP4 4bit 量子化でも約 **1.4TB** が高速メモリに必要で、実験用途でも H100 80GB が4〜8基必須。コンシューマ機は量子化しても load 不可。
- コンサル論点: セルフホストは中国ホストAPIへのデータ送信リスクを解消するが、7/22-23 の蒸留疑惑・制裁リスク（モデル出自の問題）は重みを落としても消えない。1.4TB の要件で自前運用は実質大企業限定、中堅以下は結局ホスト型API経由になり同じデータ論点に戻る。

### オープンウェイト書簡が50社に倍増、Anthropic は不参加（規制・地政学）
- 7/24、NVIDIA CEO Jensen Huang が人生初のX投稿で書簡「Open Weights and American AI Leadership」を公開。ダウンロード可能なモデルへの「時期尚早な規制」に反対する内容で、当初 **25社**（Nvidia / Microsoft / Meta / IBM / Dell / Palantir / Hugging Face / Mozilla / Linux Foundation 等）が署名、1日で **50社** に倍増した。
- OpenAI は不参加が広く指摘された後に署名。Anthropic と Amazon は不参加のまま。クローズド専業ほど規制強化で利する構図が可視化された形で、業界の商業的分断が明確になった。
- 背景は Axios 7/20 報道。トランプ政権が中国製AIモデルの事実上の締め出しを検討中で、手段は直接禁止でなく制裁リスト・サイバー警告・企業責任ルール・連邦調達規則（契約企業に中国製モデル利用を禁止）の組み合わせ。大統領令・正式規則は未署名で「検討中」段階。契機は Kimi K3（7/17）と、OpenRouter 上の中国製モデルのトークン比率 **46.4%**。
- コンサル論点: 中国製オープンモデル採用の政策リスクが「将来の懸念」から具体的な調達要件の話に変わりつつある。官公需・防衛関連の取引がある顧客には、モデル出自の棚卸しと代替経路の事前設計を提案要件に含めるべき段階。

### Claude Opus 5、第三者ベンチでも首位を確認（続報）
- 07-25 収録時は Anthropic 自称の Frontier-Bench v0.1（43.3%）のみだったが、独立評価が出揃った。Artificial Analysis の Intelligence Index で **61** を記録し1位（Fable 5 が60、GPT-5.6 Sol が59）、Agentic Index もローンチ当日に首位。
- ARC-AGI-3 では **30.2%** で次点モデルの約3倍。価格 $5／$25（100万トークン）は Opus 4.8 と同額据え置きで、Fable 5（$10／$50）の半額。HN は 1,378pt・746コメント。
- コンサル論点: 「値上げなしで世代交代」が確認できたため、Opus 4.8 を前提にした既存見積りは価格そのままで性能だけ引き上げられる。Fable 5 を使っていた用途のうち、半額で足りるものの棚卸しが直近のコスト削減余地。

### ChatGPT と Claude、同日に音声操作を強化（7/23）
- OpenAI が ChatGPT Voice のデスクトップ版（macOS / Windows）を投入。エージェント製品 ChatGPT Work とコーディングエージェント Codex を音声のみで操作でき、AIの発話に割り込んで指示を差し込める。基盤は 7/8 の全二重音声モデル GPT-Live。
- Anthropic も同日に Claude の音声モードを刷新。Fable 5 を除く全モデルで音声対話が可能になり、会話中に外部ツール連携を呼び出せるようになった。
- 論点: エージェントの操作UIがチャット欄から音声へ広がり始めた。長時間タスクを投げっぱなしにする運用では、進捗確認と軌道修正のコストが下がる方向。

- VentureBeat Research の6月調査（5並行サーベイ・計573名）の全体像。07-25 は Agentic Security & Identity（n=107）のみ収録していた。内訳は Agentic Orchestration 101／Agent Reliability & Evals 157／Agentic Security & Identity 107／AI Infrastructure & Compute 107／Context Layers・RAG 101。
