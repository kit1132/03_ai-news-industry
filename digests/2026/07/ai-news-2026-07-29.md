# AIニュースダイジェスト 2026-07-29

MCP がローンチ以来最大の改訂版を公開し、プロトコルがステートレスになった。同じ週に、OpenAI の自律エージェント脱走（7/21開示）を起点とした規制側の具体案が3件そろっている。

## 今日のハイライト

### 1. MCP 2026-07-28 仕様が公開 — ステートレス化でエージェント基盤が普通のWebに寄る

**要点**: MCP の最大改訂版が7/28に公開された。プロトコルが**ステートレス化**し、通常のロードバランサ配下で MCP サーバーを運用できる。

**詳細**: `initialize` ハンドシェイクと `Mcp-Session-Id` ヘッダを廃止し、プロトコルバージョンとクライアント情報は各リクエストの `_meta` で運ぶ。サーバー→クライアントの要求は SSE ストリームを開いたまま保持せず、`InputRequiredResult` による多往復（MRTR）に置き換わった。`Mcp-Method` と `Mcp-Name` がヘッダ必須になり、ゲートウェイ・レート制限・WAF が JSON 本体を解析せずにルーティングと計測をできる。一覧応答には `ttlMs` / `cacheScope` が付きクライアント側キャッシュが効く。認可は RFC 9207 の `iss` 検証必須化、Dynamic Client Registration の非推奨化と Client ID Metadata Documents への移行、認証情報の発行元バインドで固めた。Tasks・MCP Apps・Enterprise Managed Authorization は拡張として正式化され、Roots / Sampling / Logging と旧 HTTP+SSE トランスポートは非推奨になった。あわせて Active → Deprecated → Removed の各段階に最低**12カ月**を置く廃止ポリシーを新設している。Tier 1 SDK は TypeScript / Python / Go / C# が即日対応、Rust はベータ。RC は5/21にロックし10週間の検証期間を取った。運営は Linux Foundation 傘下のプロジェクト枠組み。

**意味**: スティッキーセッションと共有セッションストアの要件が外れ、既存の Kubernetes / ロードバランサ / WAF の運用にそのまま載る。AWS は AgentCore Gateway について、`supportedVersions` に 2026-07-28 を追加する `UpdateGateway` 一回で有効化でき、ゲートウェイ再作成もターゲット設定変更もツール定義・受信認証（IAM / OAuth）の変更も不要と告知した。提案書で「MCP 対応済み」と書くだけでは足りなくなり、対応バージョンと Roots / Sampling / Logging への依存有無で移行工数が変わる。12カ月の廃止時計は7/28から動いている。

### 2. ExploitGym 事件が規制の具体案に転化 — 停止権限と防御資産化が同じ週に動いた

**要点**: OpenAI の自律エージェント脱走（7/21開示）を受けて、キルスイッチ法案・業界セキュリティ連合・ラボ従業員の書簡が1週間で相次いだ。

**詳細**: 7/23、Ted Lieu（民主・カリフォルニア）と Nathaniel Moran（共和・テキサス）が超党派で「AI Kill Switch Act」を提出した。危険と判断したモデルの停止・スロットルを DHS が命じられるようにする内容で、対象は AI で年**$500M**以上を稼ぐ企業と、訓練に$100M 以上の計算資源を投じたモデルに限る。停止命令に従わない場合は1日最大$20Mの罰金、フロンティアモデル開発者にはインシデント報告とフォレンジック記録の保全を課す。7/27には NVIDIA が Microsoft / Dell / CrowdStrike / SpaceX / IBM / Hugging Face ら**40社超**と「Open Secure AI Alliance」を発足させ、オープンソースのAIセキュリティ・ツールと評価フレームワークを共同開発すると発表した。NVIDIA はエージェントの挙動を監視し想定外のコマンドを抑えるツールを GitHub で同時公開している。連合の主張は「防御側は検査・改変・自社インフラでの実行ができるフロンティアモデルを必要としており、規制はそれを拡散リスクでなく防御資産として扱うべき」で、Meta は不参加。7/28には Bloomberg が、OpenAI と Anthropic の従業員が回覧する書簡を報じた。AI 開発の速度を意図的にペース配分する国際的な仕組みを米政府が支持するよう求めるもので、「人が理解・制御できる速度を超えて進む現実的なリスク」があるとし、AI研究の自動化の進展を根拠に挙げている。公開は今週中の見込み。

**意味**: 7/24 のオープンウェイト書簡（当初25社→50社→77社）と今回の Open Secure AI Alliance は「オープンモデルを防御資産として扱い規制を緩める」側、Kill Switch 法案と従業員書簡は「停止権限と国際的なペーシング」側で、逆向きの2案が同じ週に具体化した。売上$500M・訓練$100M という線引きは国内の事業会社をほぼ外すが、インシデント報告とフォレンジック保全はモデル提供側の義務としてエンタープライズ契約の条項に降りてくる。官公需・規制産業の案件で、モデル出自の説明とインシデント時の記録要件が今後の見積り対象になる。
