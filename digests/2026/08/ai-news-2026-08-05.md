### 1. Qwen3.8-Max が正式リリース — Max級が $2/$6 に降りてきて、来週オープンウェイト化する

**要点**: Alibaba が Qwen3.8-Max を正式公開した。$2/$6 で OSWorld-Verified 首位、来週オープンウェイト公開。前提は「Max級フロンティアは非公開で高価」から「自己ホスト可能な同等品が同価格帯に並ぶ」へ変わる。

**詳細**: 8月3日公開。総パラメータ **2.4兆**・1トークンあたりアクティブ95B のスパース MoE で、文脈長100万トークン、出力上限13.1万トークン、テキスト/画像/動画入力に対応する。API 単価は**入力$2／出力$6（100万トークン）**で、100万トークンの文脈全域が同一単価（5,000トークン送っても90万トークン送っても$2/$6）。明示キャッシュは作成$2.50・読み出し$0.17。ベンチマークは領域で明暗が割れている。

- OSWorld-Verified（OS・アプリのエージェント操作）: **86.1** で GPT-5.6 Sol Max 83.2・Fable 5 85.0 を上回り首位
- Terminal-Bench 2.1: 86.6 で Claude Opus 4.8 / Fable 5 の 84.6 を上回るが GPT-5.6 Sol（max）88.8 に及ばない
- SWE-bench Pro: 67.7 に対し Fable 5 は 80.0、FrontierSWE は 73.5 に対し 88.8 で、ソフトウェア工学系は明確に劣後する
- PaperBench（論文再現）は報告済みで最高スコア

オープンウェイトは Qwen3.8-Max と Qwen3.8-27B の2本を来週 Hugging Face / ModelScope で公開予定。**ライセンスは未公表**で、7/16 の Kimi K3（revenue-tiered 独自ライセンス）と 7/31 の K-EXAONE 2.0（Apache 2.0）のどちらに寄るかで調達上の扱いが変わる。2.4兆パラメータ版はマルチノード前提で自己ホストの現実解は 27B 側になる。7/19 のプレビュー時（07-21 収録）は独立ベンチ非公表・オープンウェイト日程未定だったため、単価・ベンチ・公開日程が確定したのは今回が初めて。

### 2. Codex の Auto-review が約1/10のコストに — レビュー自動化の件数制限を外せる

**要点**: OpenAI が ChatGPT アプリと Codex CLI の Auto-review を GPT-5.4 から GPT-5.6 Luna へ切り替えた。7/30 の80%値下げと合わせコストは約1/10。前提は「自動レビューは対象を絞る」から「全変更に回してよい」へ変わる。

**詳細**: モデル切り替えと単価改定の合わせ技で、OpenAI 自身が「Auto-review のコストは**約10分の1**になる見込み」と告知した。原資は 7/30 実施の GPT-5.6 Luna **入力$1→$0.20／出力$6→$1.20（-80%）**（08-01 収録）で、Terra は$2.50/$15→$2/$12（-20%）。値下げの原資について OpenAI は、GPT-5.6 Sol の GA 後に Sol 自身を Codex 上で走らせて推論基盤の GPU カーネルを最適化させた自己最適化ループを挙げ、**本番 GPU カーネル改善で提供コスト-20%**、投機的デコード改善でトークン生成効率+15%超と説明している。Luna / Terra の新単価は Codex と ChatGPT Work の利用量カウントにも反映される。あわせて API の GPT-5.6 Sol に Fast mode（標準の2倍単価・最大2.5倍スループット・知能は同一）が入っている。単価改定そのものは既収録だが、**Auto-review の実行モデルが変わった点は今回が初出**で、レビュー対象を絞っていた運用は絞り込み条件を見直せる。

### 3. エージェントの本番拡大が統制を追い越した — 統制なしの本番・拡大が41%

**要点**: Domino の639人調査で、統制なしにエージェントを拡大・パイロット中の企業が41%、統制ありの本番稼働は43%だった。前提は「エージェントはこれから統制を設計する段階」から「統制なしの本番が既に4割ある」へ変わる。

**詳細**: Domino Data Lab の第5回 Enterprise AI Report。2026年4月に北米・英国・欧州大陸の年商$100M 以上の組織で、ディレクター職以上のエンタープライズAIリーダー **639人**へ実施した調査による。**統制された本番でエージェントを稼働させている組織は43%**、これに対し**統制が伴わないまま拡大中29%・パイロット中12%の計41%**で、拡大が先行しパイロットを2倍以上上回っている。2026年の組織的優先事項の首位は「エージェント利用の拡大」（38.5%・業務ユーザーのリスキリングと同率）で、**エージェントを管理するためのガバナンス基盤への投資を含むあらゆる投資項目を上回った**。ガバナンスがAI活動に完全に追随できている組織に限れば、統制下の本番稼働は67.5%まで上がる。ROI 側は、投資額を上回るリターンが出ていない企業の割合が **57%で2025年から不変**、一方で本番化能力の改善を報告した企業は93%（前年88%）。地域差があり、投資に見合うリターンが出ていない割合は北米 51.1% に対し英国 66.9%・欧州 67.0%。7/22 公表を14日間取りこぼしており B-008 の根拠に追加。
