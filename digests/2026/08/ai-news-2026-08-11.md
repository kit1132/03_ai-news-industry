### 1. Meta が Muse Glimmer を Apache 2.0 で公開 — ローカル実行のエージェントが選択肢に戻った

**要点**: 30B のエージェント特化モデルが単一の消費者向け GPU で動くようになった。エージェント基盤の前提が「クラウド API に接続する」から「手元の端末でも完結しうる」へ広がった。

**詳細**: 8/10 に Meta Superintelligence Labs が公開した。上位モデル Muse Spark から蒸留した 30B の dense multimodal モデルで、ライセンスは **Apache 2.0**、ウェイトは Hugging Face で配布する。4bit 量子化で 55GB から 18〜20GB へ圧縮され、**24GB / 32GB VRAM** の単一 GPU（PC / Mac）に収まる。文脈長は 131,072 トークン超、画像は1枚あたり最大 4,096 視覚トークン。RTX 5090 では内蔵の DFlash 投機デコーダで約 3.1 倍に加速する。Meta 自身の準備度評価は化学・生物、サイバー、制御喪失のいずれも moderate 以下。ベンチは以下のとおり。

  - SWE-Bench Pro 51.2% / AIME 2026 94.7%（いずれも一次モデルカードの値）
  - エージェント系は MCP Atlas 75.5・DeepSearch QA 74.6・GAIA2 43.3・WildClawBench 47.6・τ³-Banking 23.5 で同クラス優位
  - Terminal-Bench 2.1 は 51.7 で、Meta 自身の比較表でも Qwen の 60.7 に劣る
  - 上位の Muse Spark 1.2 はクローズドウェイトのまま。Llama 以降クローズドへ寄っていた方針が推論コストの高騰を背景に反転した

### 2. ChatGPT Business に $125 の Premium シート — 法人の座席試算が2階層前提に変わった

**要点**: 標準の5倍の利用量と5時間上限の撤廃を月 $125 で売り始めた。法人提案の座席試算が「全員同一単価」から「利用量で2階層に割り、上位者に5倍の単価を払う」前提へ変わる。

**詳細**: OpenAI が 8/10 に発表した。Premium は **月$125/ユーザー**（年契約は月$100）で、標準シートの **月$25**（年契約$20）に対して5倍の利用量を与え、5時間の利用上限を撤廃する。同一ワークスペース内で標準と Premium を混在させ、人ごとに割り当てられる。先着 10,000 社を対象に Premium シート1席あたり $100 分（2,500 クレジット）のワークスペースクレジットを最大5席まで付与する販促があり、受付は **8/20 まで**。OpenAI は IPO 準備下で収益源を積む局面にあり、報道は本件をその文脈に置いている。エンタープライズ ARR は 2025年末の約 $2.4B から 2026年半ばに $5B 超へ伸びている。

### 3. AWS が Bedrock Agents を Classic 化 — 7/30 で新規受付終了・カタログ凍結

**要点**: 既存の Bedrock Agents は新規顧客に開かれなくなり、7/30 以降の新モデルは AgentCore 側にしか載らなくなった。AWS 上のエージェント提案は AgentCore 前提へ引き直す必要がある。

**詳細**: 2023年11月提供の Amazon Bedrock Agents が **Amazon Bedrock Agents Classic** へ改称され、**2026年7月30日**から新規顧客に開放されなくなった。同日以降は maintenance mode に入り、Classic で選べるモデルカタログは同日時点の内容で凍結される。以降に公開される新モデルは AgentCore 経由でのみ利用できる。既存の Bedrock モデル・Knowledge Bases・Guardrails は影響を受けず、許可済みアカウントは従来どおり利用できる。**提供終了日は未告知**で、AWS は Classic のワークロードを Amazon Bedrock AgentCore へ移行するよう推奨している。⚠️ 一次ドキュメント（`docs.aws.amazon.com`）はゲートウェイ拒否で本文を取得できず、二次まとめと検索スニペットの突き合わせによる。7/30 の変更を12日遅れで捕捉した。
