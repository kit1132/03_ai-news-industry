### 1. Microsoft Copilot アプリの統合が 8/18 開始 — Web URL が copilot.cloud.microsoft へ移る

**要点**: 8/18 から Microsoft Copilot の Web URL が `copilot.cloud.microsoft` へ移る。組織側で新 URL を遮断していると自動リダイレクトが効かず開けないため、前提が「何もしなくてよい」から「事前に許可リストを確認する」へ変わる。

**詳細**: Partner Center の 8/14 付告知で公表された。変更は、職場アカウントと個人アカウントを見分けやすくする視覚指標、アプリ名とアイコンの簡素化、Web アプリ URL の移行の3点にあたる。

- 視覚指標: アカウントラベル、Microsoft Entra の職場アカウントを示す**緑のシールド**、背景の差
- URL 移行: `m365.cloud.microsoft` から `copilot.cloud.microsoft` へ。旧 URL からは自動リダイレクトするが、**組織内で新 URL がブロックされている場合は除く**
- デスクトップ: Windows / Mac 版の早期プレビューが 8/18 に始まり、広範な展開は9月中旬から

Microsoft がパートナーに求めている対応は、`copilot.cloud.microsoft` が既存のネットワーク・プロキシ・ファイアウォール・アクセスポリシーで遮断されていないかの確認、`*.cloud.microsoft` の許可リストへの追加、接続検証の3点。セキュリティ・コンプライアンス・ガバナンスの制御そのものに変更はない。あわせて Windows Insider 向けリリースノート（8/14・version 152.0.4191.25）では、プレビュー期間中にタスクバーの Ask Copilot を一時的に無効化し、**Notebooks・Connectors・Vision が一時的に使えなくなる**と告知している。消費者向けと法人向けの Copilot アプリを1つの製品へ束ねる移行の一部にあたる。

- https://learn.microsoft.com/partner-center/announcements/2026-august#microsoft-copilot-app-update
- https://learn.microsoft.com/windows-insider/release-notes/apps/copilot-on-windows

### 2. Z.ai が GLM-5.3 のウェイト公開だけ延期 — 理由は自社モデルの攻撃的サイバー能力

**要点**: 8/14 公開の GLM-5.3 は DeepSWE 1.1 で 66.9% と自己申告しながら、ウェイトの公開だけ約2週間先送りされた。オープンウェイトのモデルは公開と同時に自社ホストへ持ち込めるという前提が、ラボ自身の能力申告によって崩れた。

**詳細**: Z.ai は 8/14 に GLM-5.3 を API で提供開始したが、オープンウェイトと広範な API 開放は安全性評価とハードニングの完了後、公開からおよそ2週間後に段階的に行うとしている。**主要なオープンウェイト系ラボが、自社モデルの攻撃的サイバー能力を理由に公開延期を明言した初の事例**にあたる。理由は計算資源の制約でもベンチマークを巡る係争でもない。

構成は GLM-5.2 と同じ **743B** のベース（1トークンあたり活性は約40B）で、性能差は post-training だけから出ているとしている。自己申告のベンチマークは次のとおり。

- コーディング: DeepSWE 1.1 **66.9%**・Terminal-Bench 3.0 28.3%
- サイバー: CyberGym 84.5%・ExploitBench 54.4%・ExploitGym 130（6時間予算）／105（2時間予算）
- 一般・エージェント: Humanity's Last Exam（ツールあり）62.5%・Agents' Last Exam pass@1 28.5%・AutomationBench 48.2%・GDPval-AA v2 1769

能力の裏づけとして Z.ai は、GLM-5.2 以降のモデルが **269件のオープンソースプロジェクトで 2,436件の脆弱性**を特定し、うち **1,097件が Critical / High** だったとしている。対象はシステムカーネル・ブラウザエンジン・ネットワークプロトコル・OS に及ぶ。⚠️ ベンチ値はいずれもベンダー自己申告で第三者検証値ではない（B-005 準拠）。本日 `huggingface.co/zai-org/GLM-5.3` へ WebFetch を試みたところ HTTP 401 が返り、ウェイトが未公開であることと矛盾しない挙動を確認した。
