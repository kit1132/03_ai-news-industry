### 1. OpenAI Assistants API が 8/26 に停止する — 猶予期間のない全面停止が2日後に来る

**要点**: OpenAI の Assistants API が2日後の 8/26 に停止する。`/v1/assistants` と `/v1/threads` は縮退運転も延長もなくエラーを返し、Threads を Conversations へ移す自動移行ツールは提供されない。稼働中の実装は今日から手作業の移行が要る。

**詳細**: 一次の退役ページで確定した。告知は 2025年8月26日で12カ月の予告期間があり、代替は **Responses API と Conversations API** の組み合わせ。Responses 側には deep research・MCP・computer use が乗るため機能面では上位互換だが、Assistant と Thread のオブジェクトモデルが無くなるため呼び出しの組み立てを書き直すことになる。

同じ一次ページに、提案の前提に効く退役日が半年ぶんまとまっていた。**本リポジトリはこの退役カレンダーを一度も収録していない**。

- **8月26日**: Assistants API（告知 2025-08-26）
- **9月24日**: Videos API と Sora 2 系の全モデル（告知 2026-03-24）
- **10月23日**: 旧 GPT スナップショットとそのファインチューン版（`gpt-3.5-turbo-0125`・`gpt-4-turbo`・`gpt-4o-2024-05-13`・`o1`・`o3-mini`・`o4-mini` 等。告知 2026-04-22）
- **11月30日**: Evals プラットフォーム・Agent Builder・再利用プロンプト（`v1/prompts`）の3点（告知 2026-06-03）。Evals ダッシュボードは **10月31日から読み取り専用**になり、Agent Builder の移行先は Agents SDK か ChatGPT Workspace Agents。ChatKit は存続する
- **12月11日**: `gpt-5-2025-08-07` 系と `o3-2025-04-16` / `o3-pro-2025-06-10`（告知 2026-06-11）。代替はいずれも GPT-5.6 系
- **2027年1月20日**: 旧 audio / realtime / transcription 系（告知 2026-07-20）

予告期間の方針も明記されている。**一般提供モデルは最低6カ月前、プレビューモデルは最短2週間前**の通知で退役しうる。プレビュー版を提案の構成に組み込む場合、2週間で消える前提を見込む必要がある。

### 2. GPT-5.6 Sol が $4／$20 へ値下げ — Opus 5 を入力・出力とも下回った

**要点**: OpenAI が 8/21 に GPT-5.6 Sol の API 単価を入力 $5→$4・出力 $30→$20 へ下げた。Claude Opus 5（$5／$25）を入力・出力の両方で下回り、フロンティア級モデルの単価比較が逆転した。**11月21日までの期間限定**である点が試算の前提になる。

**詳細**: 一次の料金ページとモデルページで現行単価を確定した。入力 20%減・出力 33%減で、対象は API と ChatGPT Work / Codex のクレジットに及ぶ。Pro・Plus・Business のサブスクリプション料金は変わらない。

- 現行単価（1M トークンあたり）: 入力 $4・キャッシュ入力 $0.40・出力 $20。キャッシュ書き込みは非キャッシュ入力単価の 1.25倍
- 長文の割増: **入力 272K トークンを超える要求はリクエスト全体に入力2倍・出力1.5倍**が掛かる。長文脈前提の見積もりでは実効単価が $8／$30 になるため、値下げ後も旧単価を上回る領域が残る
- 同世代の据え置き分: Terra は $2／$0.20／$12、Luna は $0.20／$0.02／$1.20 で変化なし
- モデル仕様: 文脈長 1,050,000 トークン・最大入力 922,000 トークン・知識カットオフ 2026年2月16日

⚠️ 一次ページに書かれているのは**現行単価と「少なくとも 2026年11月21日まで」という期限だけ**で、旧単価 $5／$30 は一次に記載がない。旧単価は複数の二次系統が一致しており、`.last-check-state.md` の記録とも整合するため採った。11/21 以降に $5／$30 へ戻るのか別の水準になるのかは告知されていない。

### 3. ChatGPT の広告が欧州31市場で本日開始 — 無料層に「広告なし」の前提が無くなる

**要点**: OpenAI が 8/24 に ChatGPT の広告を欧州31市場へ広げ、提供国が35カ国になった。無料・Go の利用者には広告が出る前提へ変わり、広告を避ける手段は Plus 以上への課金だけになる。社内で無料版を使わせている組織は今日から表示条件が変わる。

**詳細**: 米国での初テストから6カ月での拡大にあたり、これまでで最大の展開になる。対象はドイツ・オーストリア・スイス・フランス・スペイン・イタリア・ポーランド・ベネルクス・北欧を含む31市場。

- 表示: 広告は回答と視覚的に分離される。OpenAI 広告担当VP の Dave Dugan は、広告主が利用者のチャット履歴にアクセスすることはなく、会話の情報も広告主へ共有されないとしている
- 出稿経路: **開始時点でセルフサービスは無い**。OpenAI Ads Solutions か代理店・技術パートナー経由で、Publicis・Omnicom・WPP・Havas・Dentsu・MediaPlus の名が挙がっている。中小企業向けのセルフサーブは時期未定
- GDPR 対応: パーソナライズ配信は明示的な同意ベースで、8月14日に EU 向けプライバシーポリシーを新規公開した。⚠️ 報道では**オプトアウトで変わるのは「どの広告が出るか」であって「広告が出るかどうか」ではない**とされる
- 対象プラン: Free と Go に表示され、有料・組織プランは広告なし。欧州の Plus は約 €23、Pro は €229

⚠️ 一次告知 `openai.com/index/chatgpt-ads-expands-across-europe/` はオリジン403、`www.neowin.net` / `www.techtimes.com` はゲートウェイ拒否のため、**本文を確認できず複数の二次スニペットの一致で構成した**。国内展開は 08-13 / 08-17 に記録したとおり2026年6月に開始済みで、今回の31市場に日本は含まれない。
