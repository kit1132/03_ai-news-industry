### 1. Claude Fable 5.1 が公開された — キャッシュ読み取り75%減で、反復の多い用途の Fable 単価が引き直しになる

**要点**: Anthropic が9月1日に Fable 5.1 / Mythos 5.1 を公開した。基本単価 $10/$50 は据え置きのままキャッシュ読み取りが $1→$0.25 へ下がり、前提が「Fable は最上位で高い」から「反復が多いなら最大45%安い」へ変わる。

**詳細**: 一次のリリースノートと料金ドキュメントを WebFetch して確定した。

- 単価: 基本入力 $10・出力 $50（100万トークン）は Fable 5 から据え置きで、変わったのは**キャッシュヒット単価**である。$1 → **$0.25** へ下がり、倍率も他モデルの 0.1x に対し 0.025x だけが例外扱いになった。5分キャッシュ書込 $12.50・1時間書込 $20・Batch $5/$25 は Fable 5 と同じである
- 二次が報じるコスト影響は、標準的なワークロードで約25%減、エージェント色の強いワークロードで最大45%減である
- 仕様: コンテキストは 100万トークン、最大出力は 12.8万トークン。常時オンの適応的思考が入る。提供先は Claude API・Amazon Bedrock・Claude Platform on AWS・Google Cloud・Microsoft Foundry である
- ベンチマーク（二次報道による）: Terminal-Bench-Science 0.1 が Fable 5 の 24.7% に対し 52.6%、Terminal-Bench 4.0 が 42.0% に対し 55.8%。Mythos 5.1 の Terminal-Bench 4.0 は 60.9% である
- ⚠️ **ゼロデータ保持では使えない。** 両モデルは30日間のデータ保持が最低要件で、zero retention 契約下では提供されない。規制業種向けの提案でモデル指定に入れる前に、この1点で可否が決まる
- ⚠️ 破壊的変更が3件ある。①`tool_choice` の `any` と `tool` が 400 を返すようになり、strict tool use または structured outputs への移行が要る、②思考ブロックは同一世代か新しいモデルでのみ引き継がれる、③**2026年8月31日より後に作成したアカウント**では、システムプロンプトやツールを変更したあとに思考ブロックを再送すると 400 になる
- Mythos 5.1 は限定提供（Project Glasswing）で、審査を通したサイバーセキュリティ・ライフサイエンス組織向けである点は Mythos 5 から変わらない

### 2. Copilot が PR を承認できるようになった — 「AI は必須レビューを満たせない」という統制の前提が崩れた

**要点**: GitHub が9月1日、Copilot code review の PR 承認をパブリックプレビューで公開した。承認は**リポジトリの必須承認数にカウントされる**ため、「AI レビューは必須承認を満たせない」を前提に書いたレビュー規程は書き直しが要る。

**詳細**: 一次の changelog を WebFetch し、必須承認との関係を本文で確認した。

- 一次は「有効にすると、Copilot はリポジトリの required-approvals ルールにカウントされる承認を提出できる」と明記している。既定でレビューに付く「承認アセスメント」だけでは要件を満たさない、という区別も同時に置かれている
- 既定は**無効**で、有効化は3階層で制御する
  - Enterprise: 配下の組織が承認を有効化できるかどうかを決める
  - Organization: 組織全体で有効化・リポジトリへ委譲・特定リポジトリのみ対象・全体で無効、の4通りを選ぶ
  - Repository: 承認のオン／オフに加え、Copilot が承認してよいファイルパスを限定できる
- 新しいコミットが push されると Copilot の承認は人間のレビュアーと同様に自動で解除され、更新後のコードに対して再レビューを依頼できる
- 対象プランは Copilot Pro・Pro+・Max・Business・Enterprise である
- ⚠️ **GitHub Docs 側の記述はまだ旧仕様のままである。** 「Copilot は Comment レビューしか残さず、必須承認や CODEOWNERS の要件を満たせない」という説明が本日時点で検索に出続けており、社内規程をドキュメント経由で確認すると誤った結論になる

- https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests/

### 3. Gemini に agentic video understanding が入った — 動画のトークン試算が最大88%減の前提へ変わる

**要点**: Google が9月1日、Flash 系3モデルで動画を必要な区間だけ取りに行く方式を有効化した。長尺動画のトークン消費が最大88%・コストが最大66%下がるため、動画を含む案件の見積り根拠が置き換わる。

**詳細**: 一次の Gemini API changelog で提供開始を確認し、内容は二次の突き合わせで補った。

- 従来は動画を先頭から一定レートで走査していたが、新方式ではモデルが内部のエージェントループでツールを呼び、必要な区間だけをフレーム・音声・書き起こしのいずれかで読み込む。読む速度とチャンネルもモデルが決める
- 効果は Gemini 3.7 Flash で**トークン最大88%減・精度最大7%向上**とされ、別の二次はコスト最大66%減と報じている
- 対象は Gemini 3.7 Flash・3.6 Flash・3.5 Flash-Lite の3モデルである
- ⚠️ 一次の `blog.google` はゲートウェイ拒否のため、削減率と対象モデルは二次スニペットの突き合わせによる。API changelog 側には「長尺コンテンツで静的処理比 最大88%少ないトークン」の記載があり、この1点は一次で裏が取れている
- 料金表そのものは動いていない（下記「モデル・API・料金」参照）。変わるのは単価ではなく**同じ動画を処理するのに要するトークン数**である

## 開発ツール・エージェント

- **Claude Code 2.1.257 で自動承認の既定が絞られた** — 一次 changelog で9月1日付の新版を確認した。5日ぶりの更新で、権限まわりの既定変更が複数入っている。
  - Auto モードの containment escape ルールが変わり、**クラウドのメタデータ資格情報の取得が明示的な承認を要する**ようになった。egress 回避とテナント越えの到達も、環境が想定内と示していない限り既定では自動承認されない

  - Bash の権限チェックが、解析できない不正な形式のコマンドについて常に承認を要求するようになった。プラグインがシンボリックリンク経由でファイルを読めた不具合も修正された
  - Fable 5.1（`claude-fable-5-1`）が既定の Fable モデルになった。あわせて `timeFormat` / `timeZone` 設定、全サブエージェントへモデルを強制する `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`、セッション限定の `/effort` が入った
  - ⚠️ 08-29 / 08-30 で挙げた**承認範囲を破る欠陥6件の修正は 2.1.251 に入っている**ため、未更新の環境では権限設定が想定どおり効かない状態が続く点は変わらない
  - https://code.claude.com/docs/en/changelog
- **Claude Platform に mid-conversation の効力調整ベータが3件入った** — Anthropic が Fable 5.1 と同日に、会話の途中で挙動を変えるためのベータヘッダーを3種公開した。会話の途中に置くシステムメッセージへ `output_config.effort` を入れて1ステップ単位で効力を上下させるもの、`clear_at: "next_user_message"` でターン限定のシステムメッセージを置くもの、`thinking.display: "updates"` でツール呼び出しの合間に進捗をテキストブロックとして返すものである。いずれも専用のベータヘッダーが要る。長時間のエージェント実行でコストと可観測性を調整する余地が増えた。https://platform.claude.com/docs/en/release-notes/overview
