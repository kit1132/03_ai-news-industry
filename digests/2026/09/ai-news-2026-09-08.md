### 1. Claude Managed Agents の課金体系が一次で確定 — 常駐エージェントの月額を試算できる前提に変わった

**要点**: Anthropic の一次料金ページで Managed Agents の課金が確定した。トークンに加え**セッション実行時間 $0.08/時**が別建てで課金される。09-03 に「課金体系を追う」と残した宿題が解け、常駐型エージェントのコストを見積もれる段階に入った。

**詳細**:

- 課金は2軸で、トークンと実行時間が独立して積み上がる
  - トークン: Messages API と同一単価。プロンプトキャッシュの倍率（5分書込 1.25倍・1時間書込 2倍・キャッシュ読み 0.1倍）もそのまま適用される
  - セッション実行時間: **$0.08 / session-hour**。`running` の間だけミリ秒単位で計上し、`idle`（次のメッセージやツール確認の待ち）・`rescheduling`・`terminated` は課金対象外
  - `inference_geo: "us"` を指定した場合はトークン側に 1.1倍が掛かる
- **セッション実行時間は code execution のコンテナ時間課金を置き換える**もので、Managed Agents 利用時にコンテナ時間が二重課金されることはない。単体の code execution は組織あたり月 1,550時間まで無料・超過分は $0.05/時（コンテナ単位）で、Web 検索または Web fetch と併用する場合は無料になる
- 適用されない修飾が2つ明示された。Batch API の50%割引はセッションがステートフルで batch モードを持たないため掛からず、パートナークラウド（Bedrock / Google Cloud）でも提供されない
- 一次ページの試算例は次のとおり。Opus 5 で1時間・入力5万トークン・出力1.5万トークンなら **$0.705**（内訳: 入力 $0.25・出力 $0.375・実行時間 $0.08）。うち入力4万トークンがキャッシュ読みなら $0.525 に下がる
- ⚠️ Managed Agents はベータのままで、全エンドポイントに `managed-agents-2026-04-01` ベータヘッダが要る。⚠️ **ステートフル設計のため ZDR と HIPAA BAA の対象外**であり、ゼロデータ保持や BAA を要件にする案件には現状のまま提案できない。セッションとアップロード済みファイルは API から個別に削除できる
- ⚠️ 掲載開始日はページ内に日付表記が無く特定できない。本リポジトリは同ページを 09-03 にも取得しているが当該節を記録しておらず、**本日はじめて確認した事実**として収録する

### 2. Gemini Notebook が日次回数の上限を廃止 — 「1日◯回まで」で見積もる前提が消えた

**要点**: Google が9月2日から Gemini Notebook の利用上限を固定の日次回数から消費量ベースへ切り替え、全課金ティアへ展開している。上限の単位が「1日◯回」から「5時間ごとに回復する消費枠」へ変わり、機能別の回数で使い方を設計する前提が消えた。

**詳細**:

- 旧方式は機能ごとの日次回数だった。無料ティアが音声・動画オーバービュー3件と レポート／クイズ10件、最上位の Ultra がチャット 5,000件と音声・動画オーバービュー 200件で、いずれも1日あたりの固定枠だった
- 新方式では枠の消費量が入力と出力の重さで決まる。加算要因として次の4つが挙げられている
  - プロンプトの複雑さ
  - チャットの長さ
  - 参照ソースの数
  - 使用した機能の種類
- 短い事実確認のクエリは消費が小さく、複数ソースからの Video Overview や Slide Deck の生成は大きい。枠は **5時間ごとに回復**し、週次上限に達するまで繰り返す
- 上限に当たったときの挙動も変わり、第1希望の出力が枠を超える場合は代替の出力形式を提案する。Video Overview と Slide Deck は後回しでの生成を予約でき、完了時に通知が届く
- ⚠️ 一次の `blog.google` と `support.google.com` はいずれもゲートウェイ拒否で本文に到達できず、上記は二次複数件の一致による。⚠️ **本リポジトリは6日遅れの捕捉**にあたる
