### 1. DeepSeek V4.1-Flash がエージェント原価を2桁下げた — 長文脈の費用試算が引き直しになる

**要点**: DeepSeek が V4.1-Flash を公開し、オフピークのキャッシュ読み取りを $0.003／1M に置いた。長文脈エージェントの原価を GPT-5.6 Sol / Claude Opus 5 の単価で見積もる前提が崩れた。

**詳細**: 9月10日 04:00 UTC 提供開始。**552B** パラメータのマルチモーダルモデルで、業界初とされる Causal Encoder-Decoder（CED）構成を採る。40層を20層の causal encoder と20層の decoder に分け、入力を読む間は 8B、生成中は 16B のパラメータを活性化する。Compressed Sparse Attention 2・階層スパースインデックス・FP4 KV キャッシュを組み合わせ、長時間動くエージェントに必要な KV キャッシュ実効メモリを前世代 V4-Flash の4分の1に削減した。1Mトークンあたりの単価は、オフピークが $0.003（キャッシュヒット入力）／$0.15（キャッシュミス入力）／$0.6（出力）、ピークが $0.006／$0.3／$1.2。ピーク帯は月〜金の 01:00〜04:00 と 06:00〜10:00 UTC。⚠️ **50万トークンの再利用プレフィックス**を100リクエストで使い回す試算（＝キャッシュ読み取り5,000万トークン）では、オフピークで約 $0.15 に対し GPT-5.6 Sol が $20、Claude Opus 5 が $25 になる。ベンチは agentic 系の難関5本のうち4本で両モデルを上回り、DeepSWE v1.1 が 74.2（Sol 73.0）、CyberGym が 88.1（同 84.5）だった。⚠️ 残る1本の Humanity's Last Exam は 36.8 で、Sol 44.5・Opus 5 56.3 に届かない。一次の `deepseek.com` は未試行で、数値は VentureBeat ほか二次の突き合わせによる。

### 3. OpenAI が GPT-Live-1 を API に投入 — 音声エージェントの原価が分単価で確定した

**要点**: OpenAI が全二重音声モデル GPT-Live-1 を API で公開し、$0.05／分・秒課金として一次料金ページに載せた。音声エージェントの費用をトークン積み上げで見積もる前提が、通話時間ベースへ変わった。

**詳細**: 9月10日提供開始で、本日 `developers.openai.com/api/docs/pricing` に `gpt-live-1` の行を一次で確認した。音声セッションは **$0.05／分**で、分単位に切り上げず秒課金される。⚠️ 裏で動くモデルとツール呼び出しは通常の API 単価で別途課金されるため、実費は GPT-Live-1 がどれだけ後段へ委譲するかに依存する。全二重は「話しながら聞き続ける」構成で、発話の途中で割り込まれても応答が追随する。ストリーミングと関数呼び出しを併用でき、会話の最中に実処理を起動できる。新規音声12種・電話連携・キーワードバイアスを備え、Full Duplex Bench では `gpt-realtime-2.1` 比で **30ポイント**改善したとしている。⚠️ 同じページの転写系には `gpt-live-transcribe`（約 $0.017／分）も載っており、これは 8月26日告知の `whisper-1` ほか4件（停止 2027年2月26日）の代替にあたる。既存の `gpt-realtime-2.1` は音声入力 $32／出力 $64（1Mトークン）のままで、通話時間ベースとトークンベースの2系統が並存する形になった。

- https://developers.openai.com/api/docs/pricing
- https://www.testingcatalog.com/openai-launches-gpt-live-1-for-full-duplex-voice-agents/
