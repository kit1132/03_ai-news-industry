### 2. AI エージェント群が PaperCut を突き48カ国395組織を侵害した — 攻撃の自律化が第三者の外形観測でも確認された

**要点**: GreyNoise が、AI エージェント群による PaperCut NG/MF への世界規模攻撃を公表した。昨日の Anthropic レポートが自社ログで示した「人間は標的選定だけ」の構図が、**別ベンダーの外部観測でも裏づけられた**。

**詳細**: 9月11日公表。攻撃は **8月31日**に開始され、PaperCut NG/MF の2件の脆弱性（CVE-2026-81578 / CVE-2026-82078）を悪用した。被害は判明分で **440インスタンス**・395組織・48カ国に及ぶ。攻撃者はロシア語話者とみられ、脆弱な PaperCut NG/MF と Active Directory サーバーを置いた私設ラボで、エクスプロイトの開発とテストを行ってから展開している。⚠️ 使われたのは **OpenAI Codex のハーネスと DeepSeek モデルの組み合わせ**で、そこに市販の攻撃ツールが載る構成だった。オーケストレーションには AionUI と、エージェントへ永続メモリを与える Hindsight が使われている。標的リストの生成には Netlas のインターネットスキャン基盤が使われた。到達段階の内訳は、資格情報の窃取が280組織、OS またはドメインの機密取得が147組織、管理者権限の奪取が12組織。業種別では教育が204件と突出するが、GreyNoise はこれを狙い撃ちではなく PaperCut の顧客構成の反映と見ている。国別では米国98件が最多で、英国・フランス・スペイン・カナダが続く。⚠️ **キャンペーン開始から26秒で11組織が侵害された**と観測されており、人手による初動対応が追随できない速度域に入っている。一次の `greynoise.io` はゲートウェイ拒否のため、数値は Help Net Security ほか二次の突き合わせによる。

- https://www.helpnetsecurity.com/2026/09/11/ai-agents-papercut-ng-mf-attack-campaign/

### 3. OpenAI が Codex の実行基盤を Agents API として開放した — エージェント基盤の自作が前提でなくなる

**要点**: OpenAI が Agents API を public beta で公開し、Codex を動かしているハーネスそのものを API 化した。セッション管理・文脈圧縮・サブエージェント調整を自作する前提が、**借りてツールだけ書く**前提へ変わる。

**詳細**: 9月10日公開。一次ドキュメントで確認した範囲では、API 側が「Codex のハーネスを実行し、その下のエージェント基盤を管理する」構成で、開発者はエージェントの能力定義に集中する。自動の文脈圧縮（context compaction）・マルチエージェントのオーケストレーション・プログラム的なツール呼び出し・MCP サーバー対応が含まれる。セッションの設定・ターン・アイテムは API 側に保存されるため、会話履歴を自前で管理する必要がない。実行環境は OpenAI ホストのサンドボックス・自己ホストのサンドボックス・サンドボックスなしの3通りから選べる。サンドボックス連携先として Blaxel / Cloudflare / Daytona / DigitalOcean / E2B / Modal / Oracle / Runloop / Vercel との提携が公表されている。⚠️ **Agents API 自体の追加料金はなく**、課金はセッションが使ったモデルとツールの通常単価で行われる。⚠️ 一次の告知ページ `openai.com/index/` はオリジン403のため到達できず、提供段階（public beta・全 API 開発者が対象）と課金方式は二次の突き合わせによる。ドキュメント側は到達できたが、提供段階と課金の明記は確認できていない。
