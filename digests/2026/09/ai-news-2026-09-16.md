- 音声入力: Gemini $3.00／1M（$0.005／分）に対し OpenAI `gpt-realtime-2.1` $32.00／1M — 約10.7倍の開き

### 2. Claude Code 2.1.271 が大型更新 — サンドボックスの通信許可がコマンド単位になった

**要点**: Claude Code 2.1.271 が公開され、Bash / PowerShell / Monitor にコマンド単位の `allowed_domains` が入った。前提が「サンドボックスの通信許可はセッション一括」から「コマンドごとに絞れる」へ変わる。

**詳細**: 9月14日付で 2.1.271、9月15日付で 2.1.272（不具合修正と安定性改善）が公開された。2.1.271 は本リポジトリが追跡してきた直近のリリースで最も項目数が多い。⚠️ **09-15 の確認では「9月13〜15日付のエントリはなし・最新は 2.1.270」と記録していた**が、本日読み直すと 9月14日付の 2.1.271 が掲載されていた。同じ型の取りこぼしが本日は **Anthropic のリリースノート（9/14）と GitHub changelog（9/15）でも同時に発生**しており、B-031 が想定する「最新1件だけを見る判定の誤り」ではなく**掲載の遅れ側**に原因がある可能性が高い。修正側では、組織ポリシーのキャッシュがアカウント／組織の切り替え後も再利用される問題、エンタープライズの `managed-mcp.json` の解析失敗、クラウドセッションがサブエージェントのツール呼び出しを拒否する問題、利用上限下での fast mode 失敗、`.git/config.lock` の残存で git コマンドが壊れる問題などが挙がっている。

- `allowed_domains`: Bash・PowerShell・Monitor にコマンド単位の通信許可を指定できる（auto モードのサンドボックス時）
- `omitClaudeMd`: エージェントの frontmatter に指定すると、ユーザー／プロジェクト／ローカルの CLAUDE.md を読まずにサブエージェントを動かせる
- `--accept-command <sha256>`: `claude plugin install` / `update` で実行コマンドをハッシュ指定して承認できる
- `modelPricing` の管理設定で `multiplier` に 1 超（最大10）を指定できるようになり、Claude Code Remote セッションで fast mode が使えるようになった
- `claude self-hosted-runner --drain-marker-file <path>` でホストのドレイン状況を報告できる
- https://code.claude.com/docs/en/changelog

### 3. Claude Messages API に会話圧縮が入った — 長文脈の費用を呼び出し側で制御できる

**要点**: Anthropic が Messages API に任意タイミングの会話圧縮をベータ追加した。前提が「長い会話のトークン費用は蓄積に任せる」から「圧縮の時点を呼び出し側が決める」へ変わる。

**詳細**: Anthropic のリリースノートに9月14日付で掲載された。ベータヘッダ `compact-2026-09-04` を付けてリクエストの最上位に `compaction` パラメーターを送ると、対象メッセージを要約した**署名付きの `compaction` ブロック**が返る。以降のリクエストでは、そのブロックを当該メッセージ群の代わりに先頭へ置いて送る。⚠️ 要点は**圧縮の実行時点を利用側が決められる**ことにある。圧縮リクエストはバックグラウンドで走らせることができ、直近のターンは要約せず逐語のまま残す指定ができる。逐語で残したターンに含まれる thinking は有効なまま扱われる。⚠️ 本項も 09-15 の確認では「最新は9月10日付で追加なし」と記録していた日付に載っていたもので、ハイライト2と同じ読み直しで検出している。⚠️ 単価・レート上限の改定を伴う変更ではないため、費用への効き方は**送信トークン量の削減を通じた間接的なもの**にとどまる。削減幅を示す数値は一次に記載がない。
