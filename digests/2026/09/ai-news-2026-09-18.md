## 今日のハイライト

### 1. GitHub Actions の pull_request_target が既定で無効化 — 公開リポジトリは11月2日から

**要点**: ワークフロー実行保護が GA になり、イベントポリシーを持たない公開リポジトリでは **11月2日**から `pull_request_target` が既定で無効になる。公開リポジトリの CI は「放置しても動き続ける」前提から「期日までに明示の許可設定が要る」前提へ変わった。

**詳細**: パブリックプレビューからの GA 移行にあたり、次の機能が追加された。

- ワークフローファイル単位のポリシー: リポジトリ一律ではなく、特定のワークフローファイルに別のポリシーを当てられる
- Insights: ルールがエンタープライズ・組織・リポジトリの各階層でどう評価・強制されたかを監視できる
- REST API: ポリシーをコードとして管理できる
- Evaluate モード: 強制の前にシャドー実行でルールを試せる

既定の保護は fork の非信頼コードが secrets を持ち出す「Pwn Requests」型の脆弱性を対象とし、**対象は公開リポジトリのみ**で private / internal は既定変更の対象外。適用範囲は GitHub Enterprise・組織・リポジトリ。

- https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available

### 2. Gemini Enterprise に従量課金とコミット割引 — 席数課金前提の料金試算が引き直しになる

**要点**: Google Cloud が Gemini Enterprise に従量課金・**1年10%／3年20%**のコミット割引・プロジェクト単位のハード上限を追加した。席数×単価で積む提案の料金前提が、消費量と上限額で積む前提へ変わる。

**詳細**: 一次は 2026年8月26日付の Google Cloud ブログ。内訳は以下。

- 従量課金（PAYG）: 前払いコミットも基本サブスクリプション料も不要で、標準のモデル API 単価で課金される。提供は選抜顧客から始まり、広域展開は「近日」
- Flexible Savings Plans: 月額コミット額ベースで、1年コミットが 10%引き・3年コミットが 20%引き。下限・上限の設定はなく、既存の Google Cloud EA のコミット消化にも充当できる。self-serve と EA 向けに GA
- プロジェクト単位のハード上限: 上限に達すると API 呼び出しが一時停止し、**50%・80%・100%** の3段階でメール通知が飛ぶ。再開はコンソールの1クリック、または自動超過を有効化して消費単価へ移行する（超過分も FSP に充当できる）
- 異常検知: 通常の支出傾向からの乖離を検知し、増加を牽引した上位3 SKU を根本原因として提示する
- 遅延実行（近日）: オフピーク帯にエージェント処理を回すことで推論コストが最大 50%引きになり、通常のクォータ上限を迂回できる
- Antigravity のプール済みクォータが Gemini Enterprise サブスクリプションに同梱され、業務アプリ・開発ツール・カスタムエージェントが同じ日次枠から引く

⚠️ **発表は8月26日で、本リポジトリでは本日が初収録**（`output-style.md` の「出来事が古いこと」と「既報であること」は別、という規定に基づき採録）。二次記事は「従量課金は20席以上が対象」とするが一次に記載がなく不採録とした。

- https://cloud.google.com/blog/products/ai-machine-learning/flexible-billing-and-cost-controls-for-agents-on-google-cloud

### 3. Claude Code 2.1.274 — セッション破損と MCP 接続の修正が中心

**要点**: 9月17日付の 2.1.274 が出た。壊れた transcript の自己修復、MCP の互換・タイムアウト修正、管理設定の OpenTelemetry 出力が入り、「MCP が繋がらない・セッションが詰まる」を運用側で切り分けられる前提へ変わった。

**詳細**: 前日収録の 2.1.273（管理設定と権限チェックの修正が中心）に続く大型更新で、今回は安定性と可観測性に寄っている。

- セッション破損: `unexpected tool_use_id` の 400 エラーを無限リトライし続ける問題を修正した。壊れた transcript は可能な限り自己修復し、無理な場合は `/rewind` の案内付きエラーでループを終える
- MCP 接続: `http` 設定のサーバーが旧 HTTP+SSE しか話せず初回リクエストに 422 等を返すと接続失敗していた問題、Streamable HTTP のツール呼び出しがサーバー別 `timeout` の設定を無視して約5分で切れる問題、`listChanged` を宣言しないサーバーの list-changed 通知が反映されない問題を修正した
- MCP 権限: 403 `insufficient_scope` を「サインイン切れ」と誤報せず、不足権限を名指しして `/mcp` での再認証に誘導する
- 可観測性: `claude_code.managed_settings_resolved` OTel イベントを追加し、管理設定のソースとポリシーヘルパーの状態を出す（`OTEL_LOG_MANAGED_SETTINGS=1` で設定内容とダイジェストも記録）。`claude_code.llm_request` トレーススパンに `effort` 属性が付いた
- 起動制御: `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` で非対話の初回ターンが MCP 接続を待つ上限を指定できる（`0` は待たない）
- 権限チェック: 特殊なシェル変数をループ・代入する Bash コマンドが確認を飛ばしていた問題と、worktree 分離セッションで入れ子のシェル展開が通っていた問題を修正した
- クラウドセッション: 差分ビューに「Compare against」ブランチピッカーが付き、ベース以外のブランチとも比較できる。ルーチンは GitHub 連携が切れている間、即座に停止せず **最大72時間**リトライする
- `/code-review` は専用設定を持たないモデルでレビュー用サブエージェントを多数起動せず、軽量なインラインプロンプトを使う方式に変わった

- https://code.claude.com/docs/en/changelog
