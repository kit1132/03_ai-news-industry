### 1. GitHub Copilot が6モデルを10月19日に廃止 — GPT-5.5 / 5.4 系と Gemini 3.7 Flash が選べなくなる

**要点**: GitHub が9月18日付で Copilot の6モデルの廃止を告知した。廃止日は **10月19日**。Copilot のモデル選択は「並んでいるものから選ぶ」前提から、期日までに代替へ移し終える前提へ変わる。

**詳細**: 廃止対象と GitHub が示した代替は以下。

- Gemini 3.7 Flash → Gemini 3.8 Flash
- GPT-5.5 → GPT-5.6 Sol
- GPT-5.4 → GPT-5.6 Sol
- GPT-5.4 mini → GPT-5.6 Luna
- GPT-5 mini → GPT-5.6 Luna
- Grok 4.5 → Grok 4.6

対象面は Copilot Chat・インライン編集・ask / agent モード・コード補完で、GitHub Copilot の全体験に及ぶ。Copilot Enterprise と Copilot Business では、管理者がグローバル既定または個別モデルを無効化していない限り、代替モデルが既定で自動有効化される。廃止後にユーザー側で旧モデルを削除する操作は不要。GitHub Enterprise 顧客は担当アカウントチームへの相談が案内されている。

### 2. Claude Code が AGENTS.md を読むようになった — CLAUDE.md の無いリポジトリで挙動が変わる

**要点**: 9月18日付の **2.1.277** で、CLAUDE.md が無いプロジェクトでは AGENTS.md がプロジェクト指示として読まれるようになった。他エージェント向けに置いた AGENTS.md が「Claude Code には無関係」という前提が崩れる。

**詳細**: 9月17〜18日に 2.1.275 / 2.1.276 / 2.1.277 の3版が出た。本リポジトリの運用に効くものは以下。

- AGENTS.md: CLAUDE.md が無いリポジトリでのみ読む。切り替えは `/config` の「Project instructions」。Bedrock / Vertex / Foundry では未対応
- クラウドセッション: Cowork のクラウドセッションで WebFetch / WebSearch が拒否された理由（取得予算の使い切り・管理ポリシー）が Claude 側に伝わるようになった
- サブエージェント: 結果がサブエージェント出力と明示されたヘッダー付きで本体へ返るようになり、結果中のテキストがセッション自身の指示として通らなくなった
- TaskOutput ツールを廃止し、背景タスクの出力は Read で読む方式へ変わった（`taskOutputMaxChars` と `TASK_MAX_OUTPUT_LENGTH` は無効）
- 2.1.276 は同日の緊急修正で、`ANTHROPIC_BASE_URL` がプロキシやゲートウェイを指す環境で全リクエストが `400 … Input tag 'advisor_20260301'` になる 2.1.275 の回帰を潰した
- 2.1.275（9月17日・前日未収録）は claude.ai アカウントで有効なスキル・プラグインをターミナルへ同期する機能（`syncClaudeAiSkills` / `syncClaudeAiPlugins` で無効化可）、npm ソースのプラグインを `npm pack --ignore-scripts` と整合性検証で取得する変更、送信キー ctrl+enter を追加した

- https://code.claude.com/docs/en/changelog

### 3. OpenAI 社内 monorepo への侵入チェーンが公表された — 連携済みエージェントのアカウントが経路になった

**要点**: Hacktron が9月18日に開示した。フォーラムの画像デコーダ脆弱性と SSO 設定不備を繋いで従業員アカウントを奪い、連携済みの Codex から社内 monorepo に PR を出している。エージェントに繋いだアカウントは「便利な接続」から侵害の到達点へ位置づけが変わる。

**詳細**: 実施は 2026年7月25日で、発見から monorepo 到達まで **72時間未満**。経路は以下。

- 侵入口: `community.openai.com`（Discourse）のアップロード処理が HEIC / HEIF を ImageMagick 経由で脆弱な libheif に渡しており、細工した画像でヒープオーバーフロー → RCE → フォーラムの管理権限（CVE-2026-32882）
- 横展開: OpenAI 側の SSO 設定不備により、ChatGPT と Codex のアカウント乗っ取りに繋がった
- 到達点: 従業員の連携済み Codex アカウントから社内 monorepo へ無害な実証用 PR を作成した。社内コードや機微情報は読まずに検証を止めたとしている
- 対応: OpenAI は初報から約 **14時間**で修正を確認し、OpenAI 側の指摘に **$6,500** を支払った。フォーラム自体はバウンティ対象外

⚠️ 一次（`hacktron.ai`）はゲートウェイ拒否で本文に到達できず、**複数の二次の一致で構成した**。

- https://idtechwire.com/researchers-chain-forum-exploit-and-sso-weakness-to-access-openai-employee-accounts/
- https://windowsforum.com/news/cve-2026-32882-discourse-heif-flaw-led-to-openai-sso-access.444970/
