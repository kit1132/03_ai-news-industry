### 1. ChatGPT for Word が 10月1日から既定オンになる — Word 側の統制を先に決める必要がある

**要点**: OpenAI が ChatGPT for Word を Enterprise / Edu へ提供し、**10月1日**から Word アクセスを既定オンにする。管理者が明示的に止めない限り Word に ChatGPT が入る前提へ変わる。

**詳細**: サイドバーからメモを元にした下書き、文書の要約、選択範囲の修正、見出しと書式の調整ができる。導入は Excel / PowerPoint と同じ Microsoft アドインを使う。

- 管理面: ChatGPT 管理コンソールで Word アクセスを on / off できる。加えて Microsoft 365 管理者側でも ChatGPT アドインを許可しないと Word 上に現れない。**10月1日以降は既定が「オン」**になるため、止める判断を期日前に入れる必要がある
- 課金: Business / Enterprise / Edu では Word の利用が使用モデルの **API 単価**でトークン課金される。座席料金に含まれる機能ではない
- 同時に、テナント全体の SCIM が API Platform に対応した。Enterprise / Edu のグローバル管理者が管理コンソールの Product access から、同期済みグループを API 組織と選択したプロジェクトへ割り当てられる。メンバーは招待の承諾なしでアクセスを得て、グループ割り当ての変更に追随して API のメンバーシップが更新される

⚠️ 一次（`help.openai.com`）はオリジン403で本文に到達できず、**公表日は9月15〜19日の週内までしか特定できていない**。内容は複数の二次の一致で構成した。

### 2. Claude Code の auto mode が分類器分を課金しなくなった — auto mode のコスト前提が変わる

**要点**: 9月19日の **2.1.278** で auto mode の安全チェックがサーバー側に移り、分類器のトークンが課金されなくなった。auto mode のコストに分類器の上乗せを見込む前提が消える。

**詳細**: auto mode では、シェルコマンドやネットワークリクエストの実行前に分類器が安全チェックを走らせる。2.1.278 以降はこのチェックをセッション自身のモデルリクエストの一部としてサーバーに依頼し、サーバーが実施したぶんは課金しない。

- 対象: Claude API を使うアカウントと **Enterprise プラン**、および Claude Platform on AWS / Amazon Bedrock / Google Cloud Agent Platform / Microsoft Foundry。Pro / Max / Team プランは対象外で通知も出ない
- フォールバック: サーバーのチェックがセッションに届かなくなると Claude Code 自身の分類器リクエストに戻り、**課金も従来どおり**になる。その時点で「このセッションは対象外」という通知が出て操作が保留される（Enter で続行・Esc で中止）
- 届かない原因: 経路上の LLM ゲートウェイ / プロキシが `safeguards` リクエストフィールドを落とす、`safeguard_results` を落とす、tool-use ID を書き換える、といった加工をしている場合。プラットフォーム・リージョン・資格情報が未展開の場合もある
- 切り戻し: `CLAUDE_CODE_AUTO_MODE_SERVER=0`（Anthropic API への直接接続では読まれない）。`/status` に **Auto mode server** 行が追加され、`Enabled` / `Disabled` で現在どちらかを確認できる。この環境変数は暫定で、将来削除される可能性がある

- https://code.claude.com/docs/en/changelog
- https://code.claude.com/docs/en/auto-mode-classifier-billing
