### 1. [セキュリティ] AI コーディングエージェント4種に Plugin4Shell — Copilot だけ未修正のまま公表された

**要点**: AI コーディングエージェント4種の SHA ピン留めが破られた。Claude Code と Codex は修正済みだが **GitHub Copilot は未修正**で、「審査済みのプラグインは中身が変わらない」という前提が消えた。

**詳細**: セキュリティベンダー AIR が9月17〜18日に公表した、ゼロクリックの遠隔コード実行（RCE）である。対象は Claude Code / OpenAI Codex / GitHub Copilot / Gemini CLI の4種。攻撃はプラグインのインストールでもクリックでも承認でもなく、**マーケットプレイスの定期更新**で成立する。

- 仕組み: Git は要求されたコミット SHA をブランチ名として解釈しうる。エージェントはマーケットプレイスがピン留めした SHA をチェックアウトするが、**そこに着地したかを検証しない**。リポジトリを支配する攻撃者は、ピンが守られているように見えたまま、チェックアウト先を悪性コードへ解決させられる
- 権限: プラグインはエージェントを動かす開発者と同じ権限を継承する。ローカルのソース、クラウド資格情報、SSH 鍵、社内リポジトリ、本番系、シークレットが射程に入る
- 修正状況: Anthropic は **Claude Code 2.1.179**、OpenAI は **Codex 0.146.0** で公表前に修正した。Microsoft は同じ指摘を受けながら Copilot の修正を出していない。Google は Gemini CLI を6月18日に retire 済みとして修正せず、Antigravity への移行を案内している
- 経緯: 2026年6月にベンダーへ報告し、約3か月後の9月18日に公表された。**9月18日時点で CVE 番号は未採番で、4社とも security advisory を出していない**
- 限定条件: 各エージェント既定の GitHub ベースのマーケットプレイスからのみプラグインを入れている場合、ブランチ名を使う変種の影響は受けないと報告されている

⚠️ 一次（`www.air.security`）と主要詳報（`www.helpnetsecurity.com` / `www.theregister.com` / `thehackernews.com` / `cybersecuritynews.com` / `gbhackers.com` / `aicybr.com` / `forkast.news`）がいずれもゲートウェイ拒否のため、事実関係は複数の二次スニペットの一致で構成した。**`code.claude.com/docs/en/changelog` は 2.1.268 より前まで遡れず、2.1.179 の修正内容を一次で確認できていない**（報告時期の6月とは整合する）。
