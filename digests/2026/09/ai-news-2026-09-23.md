### 1. Claude Opus 5.5 が Fable 5.1 級の性能を $4／$20 で提供 — 最上位モデルの単価前提が半値以下に落ちた

**要点**: Anthropic が「ほとんどの作業で Fable 5.1（**$10／$50**）と同等」と位置づけるモデルを **$4／$20** で出した。最上位クラスを使うための単価前提が6割減になり、フロンティアモデルの利用を費用で見送っていた用途の試算を引き直す対象になる。

**詳細**: 9月22日公開。モデル ID は `claude-opus-5-5` で、単価は入力 $4／出力 $20（Opus 5 は $5／$25）。**キャッシュ読み取りは $0.50 → $0.20 で60%減**、キャッシュ書き込みは $6.25 → $5。Fast mode は $8／$40 で最大2.5倍速（Claude API 上のリサーチプレビュー）。コンテキストは既定で **1M トークン**、最大出力128k。Anthropic は「Opus 5 比で稼働コスト40%減」と表現しており、これは単価の2割減に加えてトークン効率の改善を含む数字である。ベンチマークは Terminal-Bench 4.0 が **66.4%**（Opus 5 は 52.3%）、FrontierCode v1.1 が **54.4%** で GPT-6 Astra の 53.3% を上回り、Anthropic は「約5分の1のコスト」と併記している。CursorBench 4.0 は 57.8%、GDPval-AA v2.1 は 1846 Elo、OSWorld 2.0 は 81.8%（部分評価）。⚠️ **API の挙動に非互換が3点ある。**

- 思考を無効化できない: `thinking: {"type": "disabled"}` は 400 を返す。`thinking` を省き `effort` で深さを制御する
- `tool_choice` の `any` と `tool` が 400 を返す。`auto` と strict tool use の併用に置き換える
- Computer use は Claude API と Google Cloud で `computer_toolset_20260801` が必須になり、`computer_20251124` は 400（Amazon Bedrock では従来どおり動作する）

提供面は Claude API・Amazon Bedrock・Claude Platform on AWS・Google Cloud・Microsoft Foundry。同日 GitHub Copilot にも追加された（Pro+ / Max / Business / Enterprise。**Pro は対象外**）。

### 3. Claude Code 2.1.280 で Pro / Team Standard の既定モデルが Sonnet から Opus へ — 何もしなくても課金対象が変わる

**要点**: 既定モデルが Sonnet から Opus に切り替わったため、Pro / Team Standard で設定を変えずに使っているだけで消費レートの前提が変わる。加えて **symlink 経由の書き込みが着地先で判定される**ようになり、`acceptEdits` と allow ルールの効き方が今日から変わる。

**詳細**: 9月22日公開の 2.1.280 で、Opus 5.5（ハイライト1参照）が既定の Opus モデルになった。あわせて **Pro プランと Team Standard プランの既定モデルが Sonnet から Opus に変更**された。権限まわりでは、symlink を経由した書き込みがツリー内の見かけ上のパスではなく**実際の着地先**で判定されるようになり、`acceptEdits`・allow ルール・auto mode のいずれも、ツリー外に着地する書き込みを承認しなくなった。auto mode の暴走も2点塞がれている。

- 安全チェックが審査を拒否した操作を繰り返し再試行する問題を修正し、一度だけ拒否して「再試行しても無駄」と通知するようになった
- 安全チェックが無応答のときに無制限に拒否を繰り返す問題を修正し、バックオフを挟んだうえで10回連続でターンを停止するようになった
- `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` が追加され、MCP ツール説明の2,048文字上限をセッション単位で変更できる

Plugin4Shell との関連では、**GitHub リポジトリ／git URL からプラグインを更新した後も `installed_plugins.json` がインストール時のコミットを保持し続ける問題**が修正された。9月18日の 2.1.277 にあったピン留め記録の修正と同系統だが、いずれも security 扱いの記載はない。
