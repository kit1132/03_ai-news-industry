### 1. [料金] Anthropic が出力前の拒否にも課金を拡大 — Fable / Opus 系で「拒否は無料」の前提が崩れた

**要点**: 出力が始まる前に分類器が拒否したリクエストは、これまで課金されていなかった。9月24日から `bio`・`frontier_llm`・`reasoning_extraction` の3カテゴリに限り、通常のリクエストと同じ単価で課金される。拒否率を無料扱いにしていた Fable / Opus 系の原価試算は、この3カテゴリの分だけ引き直しになる。

**詳細**: Claude Platform のリリースノートが9月24日付で掲載した。

- 対象モデル: 安全分類器を持つ Claude Fable 5.1・Fable 5・Opus 5.5・Opus 5
- 課金の単価: 拒否したモデルの単価で、他のリクエストと同じく課金する。レート制限にも数える
- 対象外: 上の3カテゴリ以外と、カテゴリが `null` の出力前拒否は引き続き課金しない。出力途中の拒否はもともと課金対象だった
- 適用範囲: Claude API・Amazon Bedrock・Claude Platform on AWS・Google Cloud・Microsoft Foundry のすべて

3カテゴリは「誤検知が少ないと 2026年9月時点で測定できた」ものだと説明している。フォールバックを使う場合は、課金対象の拒否とフォールバック先のリクエストの**両方**が請求される。フォールバック先のキャッシュミス分を補う fallback credit は変わらない。対象カテゴリは今後も見直すとしており、一次の拒否カテゴリ表の「Billed before any output」列が正本になる。

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/build-with-claude/refusals-and-fallback

### 2. [廃止+破壊的変更] GitHub Actions が Node 20 を完全停止 — 回避用の変数も廃止され、未移行の JavaScript アクションは動かない

**要点**: GitHub Actions のランナーが JavaScript アクションを Node 24 だけで動かすようになり、Node 20 のまま残っているアクションは実行できなくなった。一時回避に使えた `ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION` も廃止され、止まったワークフローを設定で戻す方法はもう無い。

**詳細**: 9月23日付の changelog で「最終通知」として告知された。

- アクションの作者: `action.yml` の `runs.using` を `node24` に変えて新しい版を出す必要がある
- ワークフローの利用者: Node 24 に対応した版のアクションへ上げる必要がある
- セルフホストランナー: Node 24 は macOS 13.4 以前に対応せず、ARM32 も公式にはサポートしないため、これらの環境のランナーはサポート外になった
- 適用範囲: github.com と GitHub with Data Residency

- https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions
