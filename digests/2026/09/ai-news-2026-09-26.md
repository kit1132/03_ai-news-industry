### 1. [料金] Microsoft が Copilot を刷新し高度機能を従量課金へ — 「1ユーザー $30 で全部入り」の前提が崩れた

**要点**: Microsoft が Copilot を Home・Code・Autopilot の3構成に作り替えた。Cowork・Code・Autopilot とフロンティアモデルの利用は Copilot Credits による従量課金になる。ユーザー単位のサブスクリプションは日常用途の枠として残る。定額ライセンス数だけで組んだ M365 Copilot の費用試算は、従量分を上乗せする形で引き直しになる。

**詳細**: Microsoft Partner Center が9月25日付の告知（9月分で19件目）で、全パートナー向けに発表した。

- Home: Chat と Cowork をまとめ、Word・Excel・PowerPoint を組み込んだ
- Code: GitHub Copilot と同じ技術で、ナレッジワーカー向けにアプリを作れる
- Autopilot: テナント内で専用のエージェント ID を持ち、クラウド上で常時動く個人エージェント
- 課金: 日常の価値はユーザー単位のサブスクリプション、高度な機能は従量課金で、コスト管理の仕組みとして「FinOps for AI」を用意する

提供は Frontier プログラム経由で、二次報道によると Home と Code は数週間以内、Autopilot は9月末に private preview になる。二次では Copilot Credits を $0.01/credit、前払いプランの割引を5〜20% としているが、今回の告知に従量の単価は書かれていない。パートナー向け説明会（Partner Digital Airlift）は10月13日。⚠️ `blogs.microsoft.com` の公式ブログはゲートウェイ拒否で本文を読めず、単価と時期は CNBC・The Decoder などのスニペットによる。

- https://learn.microsoft.com/en-us/partner-center/announcements/2026-september

### 2. [期限] GitHub Copilot の既定有効化ポリシーは10月21日が設定期限 — 未設定の機能は管理者の選んだ既定値で一斉に切り替わる

**要点**: Copilot Business / Enterprise に、GA 機能を自動展開するかを決めるグローバル既定ポリシーが入った。10月22日に発効し、個別に設定していない機能はこの既定値に従う。「新機能は管理者が1つずつ承認する」前提で運用している組織は、10月21日までに既定値を選ぶ必要がある。

**詳細**: GitHub が9月24日付の changelog で告知した。

- Enabled: 現在の機能と今後の機能を既定で有効にする
- Disabled: 現在の機能は使えず、今後の機能は承認制にする
- Let organizations decide: Organization の管理者に任せる

対象は GA の Copilot 機能、対応クライアントの機能、Copilot Code Review のポリシー、MCP servers in Copilot のポリシー。Preview 機能は引き続き opt-in で、明示的に設定済みの機能は変わらない。設定期間は28日間。料金への言及はない。

- https://github.blog/changelog/2026-09-24-default-enablement-of-copilot-features-for-copilot-business-and-enterprise

### 3. [破壊的変更] Claude の Compliance API がファイル名とタイトルを返さなくなった — 過去の記録にもさかのぼって適用される

**要点**: Compliance API の Activity Feed が、ファイル名・プロジェクト文書名・アーティファクトのタイトルを返さなくなった。過去の activity も対象になる。監査ログをファイル名で突き合わせていた Enterprise の監査連携は、名前を使わない照合に作り替える必要がある。

**詳細**: Claude Platform のリリースノートが9月24日付の3項目のうち2つとして掲載した。

- Activity Feed: `filename` と `title` が空か省略になる
- ローカルセッション用エンドポイント: Excel・PowerPoint・Word・Outlook の Claude for Microsoft 365 セッション（`product_surface` が `office_agents` で始まるもの）でベータを終えた

前日は同じ日付の拒否課金だけを記録しており、この2項目は本日の再読で捕捉した（B-031 該当）。

- https://platform.claude.com/docs/en/release-notes/overview
