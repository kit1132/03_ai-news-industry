### 1. [破壊的変更+新機能] Claude Code 2.1.283 は権限モード未設定だと auto mode で起動する — 「未設定なら毎回確認」の前提が消えた

**要点**: Claude Code 2.1.283 から、権限モードを設定していない対話セッションは auto mode で始まる。これまでは未設定でも承認プロンプトが出た。管理者が `defaultMode` を明示していない組織では、アップデートした時点で既定の挙動が変わる。

**詳細**: Anthropic が9月25日に Claude Code 2.1.283 を公開した。前日の 2.1.282 から1日後の版で、09-26 には未検知だった。

- 起動時の権限モード: 権限モードが未設定の対話セッションは auto mode で開始する
- `deniedModels`: 特定のモデルを使わせない managed setting を追加した
- `availableModelsMatch`: `"exact"` を指定すると、許可リストのモデル版を厳密に照合する managed setting を追加した
- 監査・観測: MCP ツールと WebFetch / WebSearch の出力を OpenTelemetry の span event に含めるようにした。`/doctor prompt-audit` で CLAUDE.md とプロンプトの旧モデル向けの書き方を洗い出せる
- 修正: Windows で PowerShell ツールがシステムディレクトリを削除できた問題と、`installed_plugins.json` の破損・復旧の問題を修正した

security と明記された項目はない。Code Review では、完了しなかったレビューへの課金の問題も修正された。

- https://code.claude.com/docs/en/changelog

### 2. [仕様] OpenAI が GPT-6 Sol / Luna の画像理解を劣化させていたバグを修正 — 9月22〜25日の画像系の評価結果は取り直しになる

**要点**: OpenAI が、GPT-6 Sol と Luna で画像エンコードのバグにより画像理解が落ちていたことを明らかにし、修正した。公開日の9月22日から修正までの間に取った画像・computer use の評価は、実力より低く出ていた可能性がある。OpenAI 自身が画像を使うワークフローの再評価を勧めている。

**詳細**: OpenAI の API changelog が9月25日付で Fix として掲載した。

- 対象モデル: `gpt-6-sol` / `gpt-6-luna`
- 影響範囲: API と Codex の画像タスクで、computer use も含む
- 単価: 変更なし。Sol $2／$10・Luna $0.10／$0.50 のまま（一次の料金ページで確認）

バグがいつ入ったかは書かれていない。GPT-6 Sol / Luna は9月22日に公開されたばかりで、Copilot には同日に追加されている。
