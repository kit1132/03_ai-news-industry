### 1. Claude Sonnet 5.5 が公開、単価据え置きで破壊的変更5点 — 移行は ID 差し替えだけでは済まない

**要点**: Anthropic が9月28日に Sonnet 5.5 を公開した。単価は Sonnet 5 と同じ $2/$10 だが、thinking 無効化と強制ツール呼び出しが 400 になり、ID の差し替えだけでは移行できなくなった。

**詳細**: 入力 $2・出力 $10・キャッシュ読み取り $0.20（100万トークンあたり）で、トークナイザーも Sonnet 5 と同じ。Claude API・Bedrock・Claude Platform on AWS・Google Cloud・Microsoft Foundry で即日提供された。公称ベンチマークは Sonnet 5 比で Terminal-Bench 4.0 が 70.6%（同 10.3%）、OSWorld 2.1 が 80.1%（同 57.0%）、CursorBench 4.0 が 55.5%（同 34.1%）。破壊的変更は次の5点。

- thinking の無効化: `disabled` は 400 になり、`between_tools` を送る（effort が `high` 以下のときだけ有効）
- 強制ツール呼び出し: `tool_choice` の `any` / `tool` は 400。`auto` と strict tool use へ置き換える
- thinking ブロック: 生成したモデル・会話・アカウントに紐づく。8月31日以降に作成したアカウントでは、履歴を編集して再送すると 400 になる
- computer use: Claude API と Google Cloud では旧 `computer_20251124` を受け付けない
- advisor tool: Opus 4.8 / Opus 4.7 / Sonnet 5 を advisor に指定できない

ツール呼び出しの合間のテキストは既定で空の thinking ブロックとして返るため、途中経過を画面に流すアプリはエラーなしで黙る。Haiku 5.5 は「数週間以内」とされた。

### 2. Claude Code 2.1.284 で既定の Sonnet が 5.5 に — 管理者向けに権限バイパス禁止のポリシーも追加

**要点**: 9月28日公開の 2.1.284 で既定の Sonnet が 5.5（100万トークン文脈）に替わった。権限バイパス禁止などの管理ポリシーも入り、auto mode 既定化の抜け道を組織側で塞げるようになった。

**詳細**: auto mode で作業ディレクトリ外を読む場面に「今回だけ許可（次回も確認）」の選択肢が加わった。セキュリティ修正は、再開セッションでの MCP ツール呼び出し、危険な `rm` の確認表示、シンボリックリンクの扱いの3点。ゲートウェイは Google Cloud への OTLP エクスポートと、ID プロバイダーのクライアント証明書認証に対応した。前版 2.1.283（9/25）では権限モード未設定の対話セッションが auto mode で起動するよう変わっており、今回の2ポリシーはその管理側の対になる。

- https://code.claude.com/docs/en/changelog
