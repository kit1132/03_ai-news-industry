### 1. [料金] ChatGPT Pro 200 の利用枠が10月30日に半減、$500 の Pro 500 を新設 — $200 で足りていた試算が崩れる

**要点**: OpenAI が DevDay（9月29日）で Pro 200 の Work・Codex 枠を10月30日から半減すると発表した。同じ使い方を続けるなら $500 の Pro 500 が前提になり、1人あたり費用の試算は引き直しになる。

**詳細**: Pro 200 の変更点は次の2つ（報道ベース。`openai.com` はオリジン403のため一次未確認）。

- Work・Codex の利用枠: Plus 比 20倍 → 10倍
- GPT-6 Pro のチャット: 週200件 → 100件

既存の Pro 200 契約者は10月29日まで現行枠のままで、年末に失効する $2,500 の一回限りの利用クレジットが付く。新設の Pro 500 は月額 $500 で、利用枠は Plus 比 25倍、GPT-6 Astra の高速版 Astra Ultrafast（Codex で最大毎秒300トークン・標準の最大8倍）と常駐エージェント Dot を含む。Astra Ultrafast を使える個人プランは Pro 500 だけで、法人は Enterprise で提供される。

### 2. [料金+新機能] GPT-6.1 Sol が API と GitHub Copilot に同日投入、キャッシュ単価は半額 — Sol 系の単価表が差し替わる

**要点**: OpenAI が9月29日に `gpt-6.1-sol` を公開した。入出力は $2/$10 で据え置きだが、キャッシュ読み取りが $0.20 → $0.10 に半減した。Copilot でも同日 GA となり、試算は 6.1 基準になる。

**詳細**: 一次の changelog と料金ページで確認した値は次のとおり（100万トークンあたり、272K トークン以下のプロンプト）。

- `gpt-6.1-sol`: 入力 $2・キャッシュ読み取り $0.10・キャッシュ書き込み $2.50・出力 $10。長文脈は $4 / $0.20 / $15
- `gpt-6-sol`（旧）: 入力 $2・キャッシュ読み取り $0.20・出力 $10
- `gpt-6-astra` の Ultrafast（`service_tier: "ultrafast"`）: $60 / $6 / $300 で標準（$10 / $1 / $50）の6倍。グローバル処理と米国データレジデンシーのみ対応し、EU は未対応

Chat Completions と Responses の両 API で使えるが、ツール呼び出しには Responses API が必要。GitHub Copilot では Pro+・Max・Business・Enterprise を対象に段階展開が始まった（Pro は対象外）。Sonnet 5.5 と同じく、組織の既定設定では新モデルが自動で有効になる。

### 3. [新機能] Claude Code 2.1.285 で接続先 API プロバイダーを管理設定で制限可能に — 直接 API への持ち出しを組織側で止められる

**要点**: 9月29日公開の 2.1.285 に管理設定 `allowedProviders` が入った。端末の接続先を Bedrock や Vertex AI などに限定でき、個人 API キーでの社外経路への流出を設定で防げるようになった。

**詳細**: 追加された主な設定・コマンドは次のとおり。

- `allowedProviders`: Anthropic API・カスタムエンドポイント・Bedrock・Mantle・Vertex AI・Foundry・Claude Platform on AWS・Cloud gateway から許可先を選ぶ
- `CLAUDE_CODE_DISABLE_WEB_FETCH`: WebFetch ツールを環境変数で無効化する
- `claude --desktop`: 現在のディレクトリ、または `--continue` / `--resume` のセッションをデスクトップアプリで開く
- `claude plugin configure`: プラグインの未設定項目を表示し、標準入力から値を保存する

前版 2.1.284（9/28）の `disableBypassPermissionsMode` などと合わせ、2日続けて管理者向けの制御が増えた。

- https://code.claude.com/docs/en/changelog
