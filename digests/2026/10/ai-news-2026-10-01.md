### 1. [廃止] Claude Sonnet 4.5 が11月30日に退役 — 下限日だけだった予定が確定した期限に変わった

**要点**: Anthropic が9月30日、`claude-sonnet-4-5-20250929` の退役を11月30日と告知した。これまでは「下限日 9/29」だけで通知がなかったが、残り約2カ月の移行期限に変わった。推奨の移行先は Sonnet 5.5 で、Sonnet 5.5 には破壊的変更が5点ある。

**詳細**: 廃止ページとリリースノートで確認した内容は次のとおり。

- 対象: `claude-sonnet-4-5-20250929`（状態は Deprecated）
- 退役日: 2026年11月30日。この日以降のリクエストは失敗する
- 推奨移行先: `claude-sonnet-5-5`。Sonnet 4.5 から直接移る手順が移行ガイドにある
- 適用範囲: Claude API・Claude Platform on AWS・Microsoft Foundry。Bedrock と Google Cloud は各社が独自の日程を決める

Sonnet 5.5（9/28 公開）への移行では、`thinking: {"type": "disabled"}` を `between_tools` に置き換えることと、`tool_choice` の any / tool が 400 を返すことへの対応が要る。ほかに下限日が近いのは Haiku 4.5（10/15 以降）と Opus 4.5（11/24 以降）で、どちらも本日時点では Active のまま。

### 2. [破壊的変更+修正] Claude Code 2.1.286 で API 失敗時の再送が1回の呼び出しあたり最大14回に — ゲートウェイの費用メーターの過少計上も直った

**要点**: 9月30日公開の 2.1.286 で、失敗した API 呼び出しを再送する上限が1回の呼び出し単位の合計になった。既定設定では最大14リクエストで止まる。Claude apps gateway の費用メーターは、1時間キャッシュ書き込みを5分の単価で計算していた誤りが直り、表示額が増える方向に変わる。

**詳細**: 運用に影響する主な変更は次のとおり。

- 再送上限: 前版で最大21回まで膨らんだ再送を、1回のモデル呼び出しにつき1つの上限で数えるようにした
- 費用メーター: 1時間キャッシュ書き込みの単価と、サーバー側ツール（Web 検索など）を使うストリーミングのターンで最初の呼び出しの入力トークンしか数えていなかった点を修正した
- `--bare`: コマンドラインで指定した MCP サーバーだけに接続し、システムリマインダーもバックグラウンドタスクも送らないようにした
- プラグイン: npm ソースが git リポジトリやフォルダーの場合はインストールを拒否し、依存関係もレジストリのパッケージからだけ入れるようにした
- 既定モデルの拒否: 既定モデルが API に拒否されたとき、同じ階層の1つ前のモデルで1回だけ再試行するようにした

2.1.284（9/28）と 2.1.285（9/29）の管理者向け制御の追加に続き、3日連続の更新になる。

- https://code.claude.com/docs/en/changelog
