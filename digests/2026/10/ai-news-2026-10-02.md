## 今日のハイライト

### 1. [破壊的変更] GitHub Actions の保持期間がチェック・実行履歴・ステータスにも適用 — 期限切れの記録は自動削除され戻せない

**要点**: GitHub が10月1日、アーティファクトとログだけに掛かっていた保持期間設定を、チェック・ワークフロー実行・コミットステータスにも広げた。「実行履歴は無期限に残る」前提が崩れ、設定期間を過ぎた記録は自動削除され、設定を変えても復元されない。

**詳細**: 告知の内容は次のとおり。

- 設定名: 「Check, workflow run, status, artifact and log retention」に改称された
- 適用範囲: エンタープライズ・組織・リポジトリの各階層で設定した保持期間
- 上限: パブリックリポジトリは最大90日
- 復元: 設定を延ばしても、削除済みの記録は戻らない

監査や CI の実行履歴を長期の証跡として使っている組織は、保持期間を見直す必要がある。

- https://github.blog/changelog/2026-10-01-actions-retention-now-covers-checks-runs-and-statuses

### 2. [破壊的変更+新機能] Claude Code 2.1.287 でプラグインが深い挙動まで変更可能に — MCP サーバーが繋がらなくなる場合の回避設定も追加

**要点**: 10月1日公開の 2.1.287 で、プラグインが Claude Code の深い挙動を変えられる「Claude Mods」が入った。あわせて MCP の 2025-11-25 プロトコルの URL プロンプトに対応し、更新後に接続できなくなった MCP サーバーには設定の追加が必要になった。

**詳細**: 運用に関わる変更は次のとおり。

- Claude Mods: プラグインがより深い挙動を変更できるようになった
- You should know: サイドエージェントが見落としを指摘する組み込み mod。`/plugin enable cc-plugin-you-should-know@builtin` で有効化する（ファーストパーティのセッションでテレメトリが有効な場合のみ）
- MCP: 更新後に接続できなくなったサーバーは、その設定エントリに `"bareElicitationCapability": true` を加える
- OpenTelemetry: `user_prompt` イベントに `prompt_text` が加わった。`prompt` をマスクしている環境では同じ扱いが要る
- Windows: Bash ツールを拒否すると PowerShell ツールも無効になる場合に起動時の警告を出す

2.1.284（9/28）から4日連続の更新になる。

- https://code.claude.com/docs/en/changelog

### 3. [新機能] GitHub Copilot がデスクトップアプリを操作できる computer use をパブリックプレビューで公開 — 組織設定で無効化できる

**要点**: GitHub が10月1日、Copilot CLI と GitHub Copilot アプリで、デスクトップアプリの画面を読み取ってクリック・入力・スクロールまでこなす computer use を公開した。Copilot の操作範囲がエディタとブラウザの外に広がり、管理側には無効化の判断が新たに必要になった。

**詳細**: 対応 OS は macOS と Windows。CLI では `/computer on`、アプリでは Settings > Computer Use から有効にする。アプリを操作する前にユーザーの承認が要り、承認済みアプリは見直し・リセットできる。組織の管理設定で機能自体を無効にできる。macOS ではアクセシビリティと画面収録の権限付与が求められる。対象プランとプレミアムリクエスト倍率は告知に記載がない。

- https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps
