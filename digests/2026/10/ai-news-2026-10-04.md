### 2. [セキュリティ+新機能] Claude Code 2.1.288 が `rm` の保護が外れる不具合を直した — `~` やワイルドカードへのリダイレクトで確認が飛ばされていた

**要点**: Anthropic が10月2日に Claude Code 2.1.288 を出した。`~` やワイルドカードのパスへリダイレクトすると危険な `rm` コマンドの保護が効かなくなる不具合を直している。2.1.287 以前では、この形の削除コマンドに確認が掛からないまま実行されうる。

**詳細**: 主な変更は次のとおり。

- 修正: 長い会話の「Prompt is too long」エラーを自動 compact で回避する。非対話セッションとサブエージェントで応答の途中に API がタイムアウトする不具合も直した
- 修正: Mantle 経由や、構造化出力を拒否するゲートウェイの背後で、セッションタイトルとメモリ想起が失敗していた
- 追加: mod がフルスクリーンモードで選択テキストを読める `$.ui.selection()`。Ctrl+C で消したプロンプトの復元
- 追加: GitHub CLI が入っていないクラウドセッションに組み込みの `gh api` が入った
