### 1. [料金] OpenAI が API の利用ティアを5段階から3段階に統合 — 最上位の条件が累計 $1,000 から $500 に下がった

**要点**: OpenAI が10月6日に、API の有料利用ティアを Tier 1〜5 から Build・Launch・Grow の3段階にまとめた。最上位の Grow は累計 $500 の支払いで到達する。「本番規模のレート上限には累計 $1,000 と待機日数が要る」という見積もりの前提が変わった。

**詳細**: changelog とレート制限ガイド（いずれも一次）による。既存の有料組織は新ティアへ自動で移り、対応は不要。

- Build: 累計クレジット購入 $5 以上、月額利用上限 $500
- Launch: 同 $100 以上、月額利用上限 $5,000
- Grow: 同 $500 以上、月額利用上限 $200,000。Luna の例で 30,000 RPM・1億8,000万 TPM（Build は 5,000 RPM・200万 TPM）
- 待機日数: 旧ティアは「初回支払いから7〜30日」の条件があったが、新ガイドの到達条件は累計購入額だけを挙げている
- 無料枠: 対象地域で月 $100 上限のまま

- https://developers.openai.com/api/docs/changelog
- https://developers.openai.com/api/docs/guides/rate-limits
- https://community.openai.com/t/update-to-openai-api-rate-limits/1403852

### 2. [新機能] OpenAI API の HIPAA 対応が管理画面から有効化できるようになった — BAA の締結がメール申請から画面操作に変わった

**要点**: OpenAI が10月5日に、API の組織設定から標準の BAA（事業提携契約）に同意して HIPAA 対応を有効化する手順を加えた。医療系の PoC で「BAA はメールで申請して返事を待つ」前提が、対象組織なら管理者が当日に設定できる前提に変わった。

**詳細**: changelog（一次）による。本日の捕捉は1日遅れ。

- 場所: API の Organization settings > General。対象は「eligible な組織」の管理者で、対象条件は changelog に書かれていない
- 従来: `baa@openai.com` に組織情報と用途を送り、回答まで1〜2営業日かかるとする解説が多かった。BAA の利用には Modified Retention の設定が前提になる（二次）
- 範囲: ChatGPT と API の BAA は別契約で、API 側の BAA は ChatGPT をカバーしない（二次）
