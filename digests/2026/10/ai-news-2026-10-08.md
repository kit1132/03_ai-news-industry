### 1. [料金+新機能] Anthropic が Claude Haiku 5.5 を公開し、小型モデルの単価を Haiku 4.5 の10分の1にした — Haiku 級の試算が桁ごと変わった

**要点**: Anthropic が10月7日に Haiku 5.5 を出した。10万トークン以下のプロンプトは入力 $0.10・出力 $0.50 で、Haiku 4.5（$1/$5）の10分の1。OpenAI の GPT-6 Luna と同じ単価になった。「Claude の小型は OpenAI より4〜5倍高い」という比較の前提が消えた。

**詳細**: 料金ページとリリースノート（いずれも一次）による。

- 単価: 10万トークン以下は入力 $0.10・キャッシュ読み $0.01・出力 $0.50。10万トークン超は入力 $0.50・出力 $2.50（Haiku 4.5 比で半額）。Batch はさらに半額
- 平均の削減幅: Anthropic は「平均で約75%安い」と説明している。Haiku 4.5 のリクエストの約90%が10万トークン以下に収まり、新しいトークナイザーでトークン数がやや増える分を織り込んだ値
- 仕様: コンテキスト100万トークン・最大出力12.8万トークン。effort パラメータ付きの adaptive thinking に対応した
- 移行の注意: `budget_tokens` による手動の extended thinking は 400 エラーになる。adaptive thinking が既定でオンのため、応答が `thinking` ブロックから始まることがある
- 性能（自社公表）: OSWorld 2.1（オフライン部分集合）72.4%（Haiku 4.5 は 15.7%、Sonnet 5.5 は 83.9%）、Terminal-Bench 4.0 39.2%（同 0.0%・70.6%）
- 同時改定: Sonnet 5.5 のキャッシュ読みを $0.20 → $0.10 に半額にした。Anthropic はエージェント用途で約20%安くなるとしている。⚠️ 料金ページの表は本日時点で $0.20 のままで、同じページの本文とリリースノートは $0.10。一次の中で値が食い違っている
- Haiku 4.5: 廃止ページでは Active のまま（退役の下限は10月15日以降）で、退役の告知は出ていない

### 2. [料金] Claude Max と Team に毎月の API クレジットが付くようになった — サブスク契約だけで API の試作費を賄える

**要点**: Anthropic が10月7日に、Claude Max と Team のプランに毎月の API クレジットを付けた。Team は1席あたり $20〜$100、上限 $500。「チャットのサブスクと API は別予算」という前提が変わり、小規模な PoC ならチャットの契約費の中に収まる。

**詳細**: 一次ドキュメントによる。

- 金額: Max 5x は月 $100、Max 20x は月 $200。Team は Standard 席 $20・Premium 席 $100 を合算し、上限は月 $500
- 対象: Claude API・Managed Agents・Agent SDK・Playground。Claude Code と、Claude アプリの追加利用には使えない
- 失効: 請求サイクルごとに失効し、繰り越さない
- 条件: Console の組織を1つだけ紐づける。紐づけ先を自分で変えることはできない。新規の契約者が請求できるのは7日後から。Free・Pro・Enterprise は対象外
- 利用上限: クレジットが月 $200 を超える組織は Build ティア以上になる。ただし、クレジットの消費は上位ティアへの昇格条件に数えない

- https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers

### 3. [新機能] GitHub Copilot のローカルサンドボックスが GA になった — エージェントのファイル・ネットワーク権限を組織のポリシーで固定できる

**要点**: GitHub が10月7日に、Copilot CLI・Copilot アプリ・VS Code（Agent Host）のローカルサンドボックスを GA にした。追加料金は無い。これまで開発者ごとの設定に任せていたエージェントのファイル・ネットワーク権限を、Enterprise 側から強制できるようになった。

**詳細**: changelog（一次）による。

- 仕組み: Microsoft eXecution Container（MXC）で、共通のポリシーを Windows・macOS・Linux それぞれの OS の制御に変換する
- 制限できる対象: ファイルシステム・ネットワーク・ローカルネットワーク・Git と GitHub CLI の認証情報。ローカルの MCP サーバーと言語サーバーにも、対応していれば掛けられる
- 管理: Enterprise の管理設定でサンドボックスを必須にでき、開発者はそのポリシーを緩められない。既定でオンかどうかは記載が無い

- https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available
