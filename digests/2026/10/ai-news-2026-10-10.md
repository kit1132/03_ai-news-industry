### 1. [廃止] Gemini API の Deep Research エージェント旧プレビューが10月23日に停止する — 告知から停止まで15日しかない

**要点**: Google が10月8日に、Gemini API の `deep-research-pro-preview-12-2025` エージェントを10月23日に停止すると告知した。移行先は4月版のプレビュー2種で、どちらもプレビューのまま。リサーチ処理を組み込んだ社内ツールは、2週間で `agent` 指定の書き換えが必要になった。

**詳細**: Gemini API changelog（一次）による。10-09 は同ページを確認していたが10月8日付を取りこぼしており、1日遅れの捕捉。

- 停止対象: `deep-research-pro-preview-12-2025`（10月23日）
- 移行方法: `interactions.create` の `agent` パラメーターを `deep-research-preview-04-2026` または `deep-research-max-preview-04-2026` に変える
- 料金差・機能差: changelog には書かれていない

- https://ai.google.dev/gemini-api/docs/changelog

### 2. [仕様+予定] Anthropic が利用ポリシーを改定し、11月12日に発効する — 物理機器を動かすエージェントに停止手段の確保が求められる

**要点**: Anthropic が10月8日に利用ポリシーの改定を公表した。大半は既存ルールの明確化だが、Claude が物理的な動作をする機器を制御する場合に、人が監視して止められることと、切断時に安全な状態を保つことが新たに必須になる。発効は11月12日。

**詳細**: Anthropic の告知（一次）による。サイバーセキュリティの規定は変わらない。

- 欺瞞行為: 偽アカウント・偽ニュースサイト・影響工作の規定を、政治と商業の両方を対象にした1節にまとめた
- 選挙: 個別化した投票・選挙運動ターゲティングの一律禁止を外し、有権者を欺く行為と選挙妨害に絞った
- 監視・法執行: 同意のない追跡（収集済みデータの分析を含む）と、捜査・逮捕・起訴の対象の決定や推薦を禁止した
- 高リスク用途: 健康・法的権利・金融・生計に関わる用途は、従来どおり有資格者の関与と本人への通知が要る。対象となる推薦の種類を列挙した
- モデルへの虐待: 目的のない執拗な虐待を禁止した。通常の苛立ちやテストは対象外としている
- 対応地域: 未対応地域に本社を置く企業と、そこから過半数の出資・支配を受ける企業も利用できないと明記した

- https://www.anthropic.com/news/2026-usage-policy-update

### 3. [セキュリティ+新機能] Claude Code 2.1.296 で、Shift-JIS などのファイルを編集すると文字化けしていた問題が止まった — 非 UTF-8 のファイルは編集を拒否するようになった

**要点**: Anthropic が10月9日に Claude Code 2.1.296 を出した。Edit と NotebookEdit が Shift-JIS などの非 UTF-8 ファイルを編集すると、日本語などが壊れていた。今後は編集自体を拒否する。Bash の自動承認をすり抜ける抜け道も1件ふさいだ。

**詳細**: 公式 changelog（一次）による。

- セキュリティ修正: `BASH_ARGV0` を代入して使うコマンドを Bash の権限チェックが自動承認していた問題を直した。フォルダー単位で無効にした `.mcp.json`・プラグインの MCP サーバーを、ヘッドレス実行が起動していた問題も直した
- 管理設定のフック: `"continue": false` で拒否する管理設定の `PreToolUse` フックが、ターンを終わらせずに呼び出しだけを拒否するようになった
- 新機能: サブエージェントの定義に `autoCompactWindow` を追加し、本体より早く自動圧縮できるようにした。`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` でワークフローの全エージェントを1つのモデルで動かせる
- 既定の変更: MCP ツール説明とサーバー指示の上限を 2,048字から 4,096字に広げた。`/cost` と `--max-budget-usd` は Sonnet 5.5 のキャッシュ読みを $0.10 で計算する（10/7 の値下げの反映）

- https://code.claude.com/docs/en/changelog
