# AI ニュースダイジェスト 2026-10-15

## 今日のハイライト

### 1. [破壊的変更+新機能] Claude Code 2.1.299・2.1.300 で MCP の許可ルールが完全一致になった — 前方一致に頼った設定は黙って効かなくなる

**要点**: Anthropic が10月14日に Claude Code 2.1.299 と 2.1.300 を出した。`mcp__a` のような許可ルールが `a__b` という別サーバーに一致しなくなり、`claude remote-control` の `--sandbox` フラグは削除されてエラー終了になった。既存の settings.json やスクリプトは、更新後に許可が外れたり起動に失敗したりしうる。

**詳細**: 一次は Claude Code の changelog。

- MCP 許可ルール（2.1.299）: 完全一致になった。サーバー配下をまとめて許可するには `mcp__<server>__*` と書く。エージェント定義の `tools:` も指定したサーバーのツールだけを取る
- `remote-control`（2.1.300）: `--sandbox`・`--no-sandbox` を渡すとエラー終了する。settings の `sandbox.enabled` で指定する
- フック（2.1.300）: PreToolUse・PermissionRequest の `updatedInput` を検証し、未知のキーは捨て、ツールが拒む入力は呼び出しを拒否する。`UserPromptSubmit` はスキル展開の前に走るようになった（2.1.299）
- アイドル圧縮（2.1.299）: 20万トークン超の会話を約54分放置すると、1時間のプロンプトキャッシュが切れる前に自動で圧縮する。`"idleCompaction": false` で無効化できる
- その他: api.anthropic.com への大きなリクエストはテレメトリ無効でも gzip 圧縮される（`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` で停止）。トレースに OpenTelemetry GenAI 規約の属性が付く

- https://code.claude.com/docs/en/changelog
