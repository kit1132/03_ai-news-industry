### 1. [動向] Accenture が Claude Enterprise の利用を1人月 $29 に制限 — 「全社員に無制限で配る」導入モデルが大手でも崩れた

**要点**: 404 Media によると、Accenture が10月1日から Claude Enterprise を従量課金に切り替え、1人あたり月 $29 を超える分はプロジェクトやチームの負担にした。月 $1,000 使う社員もいた状態から予算枠方式へ移り、全社展開の費用試算は「席数×定額」では済まなくなった。

**詳細**: 一次は 404 Media の社内通知報道で、日本語は GIGAZINE（10/16）。Accenture の公式発表ではない。

- 上限: 1人月 $29（約4,600円）。割り当ては優先度と利用状況で見直され、継続利用は保証されないと通知した
- 超過分: プロジェクト・チーム単位で負担する。利用料が $500 を超えた社員が上位プランへの切替を求めたが、サポートページでブロックされたという
- Accenture の説明: 全社員が AI を使える状態は維持し、価値の大きい機能と活用支援への投資は続けるとした
- 背景: 利用量を最大化する「トークンマキシング」の見直しが業界で進み、Microsoft も社内の AI 利用に制限を設け始めたと報じられている。Accenture は Anthropic と評価・レッドチーミングの提携を詰めている相手でもある（10/16 既報）

- https://gigazine.net/news/20261016-accenture-ai-limit/

### 2. [新機能] GitHub の OSS ライセンス準拠チェックが GA — 依存パッケージのライセンス違反をマージ前に止められるようになった

**要点**: GitHub が10月16日に、エンタープライズ全体のライセンスポリシーで依存関係を検査する機能を正式提供した。ルールセットで「マージ前にライセンス準拠結果を必須」にでき、コーディングエージェントもこの判定で不適合パッケージを避けられる。ライセンス審査を人手のレビューから PR の必須チェックへ移せる。

**詳細**: 一次は GitHub changelog。6月のパブリックプレビューからの GA。

- 対象: GitHub Enterprise Cloud（データ所在地版を含む）で、GitHub Code Security を有効にしたリポジトリ。料金の記載はない
- PR チェック: 新規・変更された依存のうち不適合なものを注釈で示す。解消は依存の削除・置換、ポリシー修正、パッケージ例外のいずれか
- 承認ロール: 新設の「Enterprise Open-Source License Manager」が例外申請を審査する。ポリシー変更は監査ログに残り、ポリシーの取得・更新と準拠判定の API がある
- データ: ライセンス情報が依存グラフと SBOM エクスポートにも載るようになった

- https://github.blog/changelog/2026-10-16-open-source-license-compliance-generally-available
