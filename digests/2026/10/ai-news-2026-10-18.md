### 1. [廃止] 単体版 Claude Design が12月14日に閉鎖 — デザイン資産は Claude 本体の Artifacts へ移す必要がある

**要点**: Anthropic が claude.ai/design の単体版を12月14日に閉じ、Claude 本体の Artifacts に統合する。移行できるのはデザインシステムだけで、プロジェクト・チャット・コメント・公開リンクは移らない。「Claude Design で作ったものは残る」という前提が崩れ、期限までの棚卸しが必要になった。

**詳細**: 一次は Claude ヘルプセンターの移行ガイド。告知は10月8日だが、本ダイジェストでは未収録で、Claude Code 2.1.302（10/16）が `/design-sync` に閉鎖の通知を加えたことで初めて把握した。

- 対象プラン: Free・Pro・Max・Team・Enterprise のすべて。閉鎖後の URL は Claude にリダイレクトされ、チャットとコメントは12月中に削除される
- 移行できるもの: デザインシステム。組織内の他人が所有するものも1回の操作でまとめて移り、Artifacts ページの「Migrate team design systems」から実行する
- 移行できないもの: 空のデザインシステム、組み込みのスターターテーマから作ったもの（編集済みでも不可）、プロジェクト（移行方法は「近日案内」）、公開プロジェクトのリンク
- Team・Enterprise の管理者: Artifacts、Design systems、Design and Slides を有効にする必要がある。Enterprise ではデザインシステムが既定でオフ

- https://support.claude.com/en/articles/17440474-migrate-from-standalone-claude-design-to-claude
- https://code.claude.com/docs/en/changelog

### 2. [破壊的変更+新機能] Claude Code 2.1.302 で `claude -p` と Agent SDK の既定動作が変わった — 無人実行の権限モードとサブエージェント構成を見直す必要がある

**要点**: Anthropic が10月16日の Claude Code 2.1.302 で、`claude -p` と Agent SDK の fork サブエージェントを既定でオンにした。サードパーティプロバイダー経由で権限モードを指定していないセッションは `default` で起動するようになった。CI やスケジュール実行で前提にしていた挙動が、設定を変えないまま変わる。

**詳細**: 一次は Claude Code changelog。

- 権限モード: `claude -p` と Agent SDK で権限モードを指定していないセッションは、サードパーティプロバイダー（Bedrock・Vertex 等）でテレメトリーがオフ、または新規インストールのとき `default` で起動する。`--permission-mode auto` を明示すれば auto のまま
- fork サブエージェント: `subagent_type: "fork"` が `claude -p`・Agent SDK・デスクトップ版・VS Code で既定オンになった（ターミナルでは既にオン）。`CLAUDE_CODE_FORK_SUBAGENT=0` で無効にできる
- サブエージェントの実行: デスクトップ版と VS Code では、メイン会話のサブエージェントが常にバックグラウンドで動く。サブエージェント自身が呼ぶ Agent はフォアグラウンドが既定になった
- その他: auto mode の分類器モデルを選ぶ `CLAUDE_CODE_AUTO_MODE_MODEL` を追加した。プロンプト・エージェントフックは同一イベントで同時12件までに制限され、バグ修正は43件

- https://code.claude.com/docs/en/changelog
