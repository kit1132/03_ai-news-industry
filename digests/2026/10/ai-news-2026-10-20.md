### 1. [セキュリティ] OpenCode Console の侵害で OpenAI・Anthropic・Google の API キーが流出した — 第三者ツールに預けたキーが課金の穴になった

**要点**: OpenCode を運営する Anomaly Innovations が10月17日、廃止予定だった旧システムへの不正アクセスで、Console 利用者の 1.4% が保存していた外部プロバイダーの API キーが流出した可能性があると公表した。開発ツールにキーを預けることが、そのまま請求リスクになる前提に変わった。

**詳細**: 一次は OpenCode の公式 X 投稿で、GIGAZINE（10/19）と複数のセキュリティ系二次で確認した。Notebookcheck の本文には到達できなかった。

- 範囲: 影響は Console で外部プロバイダーを接続していた利用者に限られ、対象者には当日朝にメールで通知した。通常の OpenCode アプリの利用者は対象外としている
- 原因の説明: 同社は「大規模な蒸留攻撃に関連する」と説明したが、蒸留との関係を示す技術的な根拠は出していない。事案は継続中で、詳細は出せないとしている
- Anthropic の対応: Anthropic の Lydia Hallie 氏が、影響を受けたとみられる Claude API キーを失効させたと投稿した。キーを保存していた利用者には予防的な再発行を勧めている。Anthropic の公式発表は確認できなかった
- 被害の報告: 個人の報告では、OpenAI $281・Anthropic $168、Anthropic $400、Google 約€200 の想定外の請求などが出ている。侵害との因果は確定していない。OpenAI が返金しているとの報道は1サイトのみで、裏付けがない

### 2. [仕様] GitHub が異常トラフィック時に公開リポジトリの HTTPS clone に認証を求める — 未認証で clone する CI が止まりうる

**要点**: GitHub が10月19日、異常なトラフィックがあるあいだ、公開リポジトリへの未認証の HTTPS clone・fetch に一時的に認証を求めると告知した。「公開リポジトリは匿名で取れる」という CI の前提が、常には成り立たなくなった。

**詳細**: 一次は GitHub changelog。全プランの github.com リポジトリが対象で、開始日・終了日は書かれていない。

- 影響を受けない操作: 認証付き HTTPS、SSH、push、Web・API の通信
- 対処: GitHub Actions は組み込みの `GITHUB_TOKEN` を使う。他の CI は GitHub App のインストールトークンを推奨し、PAT でもよい
- 位置づけ: 「公開リポジトリへの一般的な認証要件ではない」と明記している。正当な通信も信号が似ていれば巻き込まれるとしている

- https://github.blog/changelog/2026-10-19-some-git-over-https-may-temporarily-require-authentication
