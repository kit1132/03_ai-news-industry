## 今日のハイライト

### 1. [料金] OpenAI が Responses API に12時間のプロンプトキャッシュを追加した — キャッシュの書き込み単価が2段になった

**要点**: OpenAI が10月20日、Responses API でキャッシュの保持時間を12時間にできるようにした。書き込みは入力単価の 2.5倍で、既定の30分（1.25倍）の2倍になる。長いシステムプロンプトを使い回す業務の試算は、「キャッシュは短時間で消える」前提から、保持時間と書き込み単価の組み合わせで比べる前提に変わった。

**詳細**: 一次は API changelog（10/20）とプロンプトキャッシュのガイドで確認した。

- 指定方法: `prompt_cache_options.ttl` に `"12h"` を指定する。ブレークポイントごとの `prompt_cache_breakpoint.ttl` で個別に上書きできる。既定は `"30m"` のまま
- 単価: 書き込みは12時間で入力単価の 2.5倍、30分で 1.25倍。読み出しはどちらも入力単価の 0.1倍（GPT-6.1 Sol は 0.05倍）
- 対象: GPT-5.6 以降のモデル。12時間は最低保持時間であり、それより長く残る場合がある。旧モデル向けの `prompt_cache_retention`（`"24h"` / `"in_memory"`）とは別のパラメーターである

- https://developers.openai.com/api/docs/changelog
- https://developers.openai.com/api/docs/guides/prompt-caching

### 2. [新機能] Claude Enterprise の Inference hooks が正式提供になった — 推論の前に自社の DLP で許可・拒否を判定できる

**要点**: Anthropic が10月20日、Claude Enterprise 向けの Inference hooks をベータから正式提供にした。プロンプトを自社のセキュリティサーバーに送り、許可・拒否の判定を受けてから推論する仕組みで、端末側に何も入れずに全製品へ掛かる。Claude の DLP は事後監査（Compliance API）だけという前提が、推論前に止められる前提に変わった。

**詳細**: 一次は platform.claude.com のリリースノート（10/20）と機能ページ。

- 対象: claude.ai・Cowork・Claude Code・Claude for Microsoft 365・Claude Tag・Claude in Chrome を1つのフックでまとめて管理する。Amazon Bedrock と Google Cloud、API 利用の Platform 組織は対象外
- 判定: 組織が運用する HTTPS サーバーが allow / deny を返す。既定のタイムアウトは5秒で、無応答時に止めるか通すかを組織が選ぶ。「Validate tool calls」をオンにすると、ツール呼び出しの前にも判定が入る
- 導入の段階: シャドーモード（ブロックせず観測）、検査する割合の指定、ロール単位の除外がある。拒否は Activity Feed に記録される
- 制約: 判定は許可か拒否だけで、書き換えや墨消しはできない。画像だけの添付は検査されない。設定できるのは Owner と Primary owner だけ

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/manage-claude/inference-hooks
