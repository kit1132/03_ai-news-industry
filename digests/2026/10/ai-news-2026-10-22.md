# AI ニュースダイジェスト 2026-10-22

## 今日のハイライト

### 1. [破壊的変更+新機能] Anthropic が API 版 2026-10-21 と SDK の新メジャー版を出した — SDK を上げるだけで temperature 指定が 400 エラーになる

**要点**: Anthropic が10月21日、2023年以来の API 版 `2026-10-21` を公開し、各言語の SDK と `ant` CLI の新メジャー版がこの版を既定で送るようにした。新版では `temperature`・`top_p`・`top_k` を送ると 400 エラーになる。SDK の更新は「上げれば済む」作業から、移行作業として計画する前提に変わった。

**詳細**: 一次はリリースノート（10/21・4項目）と移行ガイド。

- 対象 SDK: Python 2.0.0・TypeScript 1.0.0・C# 13.0.0・Go 2.0.0・Java 3.0.0・PHP 1.0.0・Ruby 2.0.0・`ant` CLI 2.0.0。旧版の SDK は引き続き `2023-06-01` を送る。旧版の停止日は書かれていない
- Messages API: サンプリング3パラメーターは既定値でも 400 になる。Sonnet 4.6 などで `temperature` を下げて出力を安定させていた処理は、その効果を失う。ほかに、assistant メッセージに直接置いた `document` ブロックと、user メッセージの `citations` も 400 になる
- Admin API・Enterprise Analytics API: 旧フィールド名を返さなくなる（`roles`→`role_ids`、`actor.email`→`actor.email_address` など）。API キーの `workspace_id` は消え、`scope` で判定する
- SDK 側の変更: API キーを `X-Api-Key` ではなく `Authorization: Bearer` で送るので、ヘッダーを見るプロキシやゲートウェイは修正が要る。Text Completions は削除された。ライセンスは MIT から Apache 2.0 に変わった
- Bedrock の制約: Amazon Bedrock では `2026-10-21` が使えるのは Claude 4.7 以降だけで、Opus 4.6 以前を呼ぶ処理は旧 SDK に留める必要がある

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/api/migration-2026-10-21

### 2. [新機能+動向] Google Cloud が OpenAI のモデルを扱い始めた — 3社のモデルを1枚の請求書で買えるクラウドが出た

**要点**: Google Cloud が10月21日、GPT-6 Astra・GPT-6.1 Sol・GPT-6 Luna を Model Garden で限定プレビューとして出した。利用は Google Cloud の既存コミットを消化し、Gemini・Claude と同じ請求書にまとまる。GPT を企業で使う経路は Azure と OpenAI 直契約の2つという前提が、GCP を含む3つに変わった。

**詳細**: 一次は Google Cloud ブログ（10/21）。OpenAI も同日に告知した。

- 提供形態: 一部の企業顧客向けの限定プレビューで、申し込みフォームから希望を出す。単価・リージョンは公表されていない
- 課金: Google Cloud Marketplace 経由で取引し、既存のクラウドコミットとモデル横断の Flexible Savings Plans に計上される
- データ: 顧客データを基盤モデルの学習に使わない。ゼロデータ保持（ZDR）と Confidential Compute は「近日」で、今は使えない
- 今後: Gemini for business と Google Antigravity への搭載は「近日」。Codex CLI・Desktop から Gemini プラットフォーム経由で推論できる
