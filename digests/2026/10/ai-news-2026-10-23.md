### 1. [セキュリティ] LiteLLM 1.107.0 に情報窃取マルウェアが混入した — Claude Code・Cursor・Copilot の認証情報も盗まれる

**要点**: LLM ゲートウェイの LiteLLM で、PyPI に出た 1.107.0 に情報窃取プログラムが入っていた。`.pth` で Python 起動のたびに動くため、LiteLLM を使わない処理からも盗まれる。「入れただけなら安全」という前提が崩れ、環境の作り直しと鍵の総入れ替えが必要になった。

**詳細**: GIGAZINE が SafeDep の分析と LiteLLM 開発チームの発表を引いて報じた。LiteLLM の GitHub advisory 一覧には本件がまだ載っておらず、一次では確認できていない。

- 公開期間: 10月21日 20:39（日本時間）ごろに PyPI へ公開され、約2時間後に削除された。一部の Docker イメージにも混入した（版は非公表）
- 侵入経路: 攻撃者がエンジニア3人の GitHub 認証情報を得て、公開手順を偽リポジトリに向けた。GitHub 上のソースには不正ファイルが無い
- 盗まれるもの: ブラウザのパスワード・履歴、SSH 秘密鍵、クラウド認証情報、AI コーディングツール（Claude Code・Cursor・GitHub Copilot）の認証情報、LiteLLM で管理する API キー
- 持続化: `sitecustomize.py` が1時間ごとに GitHub 上の指示を読み、窃取の再実行と追加プログラムの取得を行う
- 対処: 先に不正ファイル（`cook.pth`・`cook.py`・`sitecustomize.py`）を消して環境を作り直し、パスワードと API キーを変える。消す前に Python を起動すると再び動くため、通常のアップグレードから始めてはいけない

- https://gigazine.net/news/20261022-litellm-backdoor/

### 2. [破壊的変更+新機能] Claude Code 2.1.307 に API 版 2026-10-21 への移行コマンドが入った — 400 エラー対応を手作業で探さずに済む

**要点**: Anthropic が10月21日に Claude Code 2.1.307 を出し、Claude API のコードを新 API 版 `2026-10-21` へ書き換える `/claude-api api-version` を加えた。前日の新版で `temperature` 指定などが 400 になる問題は、移行箇所を人が洗い出す作業から、コマンドで当てる作業に変わった。

**詳細**: 一次は Claude Code changelog（2.1.307 は10/21、2.1.308 は10/22 で不具合修正のみ）。

- `claude_code.safety_event`: 権限ルール・auto mode・安全チェック・hook・サンドボックスがツール呼び出しを止めた、確認を求めた、差し戻したときに OpenTelemetry へ1件ずつ出す
- Code Review: `@claude review stop`（`off`・`pause` も可）で、PR の `@claude review always` 購読を止められる
- セルフホストランナー: checkout hook が既定30分で止まり、セッションの準備が失敗する。長い処理は `--checkout-hook-timeout-min` を上げるか `0` にする
- `axScreenReader`: 設定と `CLAUDE_AX_SCREEN_READER` は、ユーザー・管理・`--settings` の設定からだけ効く（2.1.305 から）

- https://code.claude.com/docs/en/changelog
