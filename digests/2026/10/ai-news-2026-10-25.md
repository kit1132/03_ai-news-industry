### 1. [新機能] GitHub が Copilot 利用指標 API にツール別の内訳を加えた — Claude Code・Codex・OpenCode 経由の利用が数えられる

**要点**: GitHub が10月23日、Copilot 利用指標 API に `totals_by_client` を加え、Claude Code・Codex・OpenCode など IDE 以外から Copilot のモデルを使った分をツール別に出すようにした。これまで IDE のテレメトリで数えていたため、IDE 外の利用は集計から漏れていた。今後はサーバー側の計測でツールごとの比較ができる。

**詳細**: 一次は GitHub changelog（10/23）。

- 対象レポート: enterprise・organization・enterprise-user・organization-user の4種で、1日版と28日版の両方に入る
- 出る値: クライアントごとのリクエスト数・セッション数・トークン数（入力・出力・1リクエスト平均）と、モデル別の内訳。モデルを選んだのが利用者・auto・製品のどれかも出る
- クライアント名: `opencode`・`claude_code`・`codex`・`zed`・`copilot_cli`・`cloud_agent`・`code_review`・`vscode`・`jetbrains` など。判別できないものは `other`
- 制約: `request_count` はプロンプト数ではなくモデル呼び出し数。クライアント判定は各リクエストが送る統合 ID に頼る推定。Copilot コードレビューのモデルは `unknown` になる
- 権限: 利用指標ポリシーの有効化が要る。閲覧はエンタープライズ所有者・請求管理者・Organization 所有者と `View Copilot Metrics` 権限を持つカスタムロールに限られる

- https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode

### 2. [廃止+新機能] GitHub の旧 Teams アプリが11月16日に退役する — Teams から Copilot を使うには統合アプリへの切り替えが要る

**要点**: GitHub が10月23日、Microsoft Teams 向けの通知アプリ「GitHub notifications」に Copilot を統合し、旧来の GitHub アプリを「GitHub (deprecated)」に改名して11月16日に退役させると告知した。Teams で @GitHub に頼むと、Copilot が調査・修正・PR 作成まで進める。旧アプリの利用者は入れ替えが必要になる。

**詳細**: 一次は GitHub changelog（10/23、Improvement 扱い）。

- 統合アプリ: チャンネル・グループチャット・個人チャットで通知を受け、@GitHub で操作を頼める。例として、Teams に届いたバグ報告から GitHub が原因を調べて修正し、PR を開く流れを示した
- 移行: 既存の GitHub notifications 利用者はアプリを更新するだけで、通知機能はそのまま動く。旧 GitHub アプリの利用者は統合アプリを新たに入れる必要がある
- 未記載: 料金・対象プラン・GA かプレビューかは書かれていない。退役日の「November 16」には年が書かれていない

- https://github.blog/changelog/2026-10-23-turn-notifications-into-code-with-github-copilot-in-teams

### 3. [セキュリティ+新機能] Claude Code 2.1.310 でクラウドセッションを Enterprise のカスタムロールで制御できるようになった — Windows のフック素通りも修正

**要点**: Anthropic が10月23日に出した Claude Code 2.1.310 で、クラウドセッションと Remote Control の権限が Enterprise のカスタムロールに加わり、Owner がロールごとに使える範囲を決められるようになった。これまでは組織単位のオン・オフしかなかった。Windows で PreToolUse フックが効かずにツールが実行される不具合も直った。

**詳細**: 一次は Claude Code changelog（2.1.310、10/23）。

- 管理: 管理画面でクラウドセッションや Remote Control をオンにすると、確認とともにその権限を持つカスタムロールが一覧される
- Monitor ツール: Bedrock・Vertex・Foundry 経由と、テレメトリや不要な通信を止めた環境でも使えるようになった
- フック修正: Windows で Git Bash が無く、フックのコマンドが引用符付きの文字列だけのとき、PreToolUse・PermissionRequest フックがツール呼び出しを通していた
- ゲートウェイ: `effort-2025-11-24` beta 値や会話途中のシステムメッセージを拒否するゲートウェイ・互換サーバーで失敗していた要求を、それらを外して再試行するようになった

- https://code.claude.com/docs/en/changelog
