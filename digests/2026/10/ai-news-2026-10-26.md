### 1. [料金+動向] OpenAI が Anthropic の大口顧客を最大9割引で奪っていると報じられた — API の定価は企業調達の基準にならなくなった

**要点**: The Information によると、OpenAI は Replit・DataCamp などの大口顧客に定価から30〜90%の値引きを出し、Anthropic から乗り換えさせている。Rippling ではコーディング用途の OpenAI の比率が16%から52%に上がった。エンタープライズ契約の実勢価格は、公開単価の比較では見積もれなくなった。

**詳細**: The Decoder（10/25）が The Information の報道として伝えた。The Information の本文は読めておらず、OpenAI・Anthropic のコメントもない。

- Rippling: CEO の Parker Conrad 氏によると、コーディング用途の比率は OpenAI が16%→52%、Anthropic が57%→18%に入れ替わった
- Replit: 年$1億超の契約に30%超の値引きを提示されて乗り換えた。CEO の Amjad Masad 氏は TechCrunch Disrupt（10/17〜10/20 報道）で、既定モデルを ChatGPT に切り替えたが Anthropic モデルも引き続き使えると話した
- DataCamp: CEO の Jonathan Cornelissen 氏によると、OpenAI の価格でコストが80〜90%下がった
- 米地銀（資産$70億超）: ChatGPT の席数を500人に倍増させても追加料金はなく、1人あたり通常$20以上のところを$7未満で払っている
- 背景: The Decoder は、値引きには利益を削って取る分と、Sol・Luna 系列の値下げ（モデルと基盤の効率化）による分があると書いた。Anthropic の成長は Q2 から Q3 にかけて鈍ったと投資家向けメモにある。The Information は 9/28 にも、Anthropic は契約トークンを使い切ると約15%の割引を打ち切るが、OpenAI は翌月末まで猶予すると報じていた

### 2. [新機能] Anthropic がサブエージェントを1本のエージェントにまとめる手引きと移行キットを出した — 新しいモデルでは単一ループのほうが速く品質も保てる

**要点**: Anthropic が10月22日、複数のサブエージェントに仕事を分ける構成を、必要なときにスキルとツールを読み込む1本のループにまとめる手引きを公開し、Claude Code 用の移行キットを GitHub に置いた。Opus 4.5 以降のモデルは1本のループで複雑な計画をこなせるようになり、分割すると遅くなるうえ引き継ぎで文脈が抜ける。

**詳細**: 一次は claude.com の記事（10/22、Diane Sarkis 氏）と GitHub リポジトリ。

- 実測: ある顧客の比較で、単一ループはマルチエージェント構成の約2倍速かった
- 目安: ツール定義が30〜50個を超えるとツールの選び方が崩れる。推奨構成はシステムプロンプト1本・薄いデータツール4〜5個・出力のガードレール
- Claude Code: 新しいモデル向けのシステムプロンプトを80%超削った。スキルとツールを必要なときだけ読み込む方式に移した
- サブエージェントを残す条件: 1本では文脈が膨らんで性能が測れるほど落ちるとき、使い捨ての文脈で並列に走らせるとき、ツール選択や指示の矛盾で迷うとき
- `single-agent-loop-kit`: Apache-2.0。Claude Code のスキルとして入れると、サブエージェントごとに「統合・合併・ツールとして呼ぶ・残す」を提案し、変更のたびに評価を回して比べる。API キー不要の模擬環境で試せる。保守はせず、issue・PR も受け付けない参照実装で、一部の手順は実モデルで未検証

- https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop
- https://github.com/anthropics/single-agent-loop-kit
