### 1. [動向] Anthropic が S-1 を公開提出し Nasdaq「ANT」で上場を申請した — 売上と損失は報道の推計から一次開示の値に変わった

**要点**: Anthropic が10月26日、Form S-1 を SEC に公開提出し、Nasdaq Global Select Market にティッカー「ANT」で上場すると発表した。6月の機密提出以来、評価額・売上・損失は報道の推計しかなかったが、目論見書の数値で引用できるようになった。ただし価格帯・株数はまだ決まっていない。

**詳細**: 一次は Anthropic の告知（10/26）。告知に載っているのは提出日・市場・ティッカーと、目論見書の入手先（Goldman Sachs・Morgan Stanley）だけで、株数と価格帯は「未決定」とある。財務の数値は SEC 本文に届かなかったため、The Decoder（10/26）などの二次報道から取った。

- 売上: 2026年上期 **$163億**、Q2 $116億、2025年通期 $46億。従量課金が約80%、定額サブスクが約20%
- 損益: 上期の純損失は **$807億**で、うち約$724億は転換社債・SAFE などの公正価値変動による非資金費用。営業損失は $6.93億（前年同期 $21億）で、Q2 単独では GAAP 営業利益 $9.74億と初めて黒字になった
- 顧客: 年$10万超の顧客は1万1,900社超、年$1,000万超は約250社。最大顧客は売上の10%未満、上位5社で約25%。Claude Enterprise と Claude Code を併用する顧客は、そうでない顧客の約20倍を支払っている
- 計算資源の契約: 報道で値に幅がある。DCD は将来の最低支払額を約$4,170億（2025年12月時点）とし、The Decoder は Broadcom・Google・Amazon・Microsoft との長期契約を約$7,800億〜$8,100億と書いた。解約不能 $546億＋最低保証 $2,656億（6/30 時点）とする要約もある。一次での確認はできていない
- 議決権: 共同創業者7人が Founder LLC を通じて Class F 株1株を持ち、主要事項の議決権の50.1%を握る。Q3 の数値は S-1 に入っていない（Bloomberg は 10/15 に Q3 売上 $168億と報道）。上場は早ければ11月中旬、評価額の目標は約$2兆と報じられている

### 2. [料金+新機能] OpenAI が GPT-6.1 Terra を $1/$5 で公開し、GitHub Copilot でも同日に GA になった — 中位モデルの単価が GPT-5.6 Terra の半額以下になった

**要点**: OpenAI が10月26日に GPT-6.1 Terra（`gpt-6.1-terra`）を API で公開した。単価は入力 $1・出力 $5 で、GPT-5.6 Terra（$2/$12）の半額以下。Copilot ではモデル選択に入り、提供元の表示単価で従量課金される。11/16 に Copilot から GPT-5.6 Terra が消えるため、移行先の単価の前提が変わった。

**詳細**: 一次は OpenAI の changelog・料金ページ・モデルページ（10/26）と GitHub changelog（10/26）。

- 単価（100万トークンあたり）: 272K トークン以下は入力 $1.00・キャッシュ $0.05・出力 $5.00、長文脈は $2.00・$0.10・$7.50。Batch と Flex は $0.50・$0.025・$2.50、Fast は $2.00・$0.10・$10.00。比較対象は GPT-6.1 Sol $2/$10、GPT-6 Luna $0.10/$0.50
- 仕様: コンテキスト 1.05M・最大出力 128K・知識カットオフ 2026年6月1日。推論レベルは none〜max の6段階で、none を持つのは主力4モデルのうち Terra だけ。用途は視覚的推論・コンピューター操作・文章生成
- GitHub Copilot: Pro・Pro+・Max・Business・Enterprise で GA になり、VS Code・Visual Studio・Copilot CLI・cloud agent・JetBrains・Xcode・Eclipse などで選べる。新モデルを自動で有効にする既定のままなら、管理者が何もしなくても有効になる。段階的に展開している

- https://developers.openai.com/api/docs/pricing
- https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot

### 3. [破壊的変更] Gemini API の新しい有料プロジェクトでリクエストが既定で保存されるようになった — 新規プロジェクトでは「送ったプロンプトは残らない」が前提でなくなった

**要点**: Google が10月26日から、有料ティアで新しく作るプロジェクトの Generate Content API で `store=true` を既定にした。プロンプトと応答は AI Studio のログに既定で55日残る。既存プロジェクトの設定は変わらないが、10/26 以降に作るプロジェクトでは、止めない限り保存される。

**詳細**: 一次は Gemini API の changelog（10/26）とログ・データセットのページ。

- 対象: 10/26 以降に作られた有料ティアのプロジェクト。それより前のプロジェクトは、AI Studio でログを有効にしていない限り `store=false` のまま。Interactions API の既定に揃えた変更
- 保持期間: 既定は55日で、7・14・28・55日から選べる。データセットに保存したログには期限がない。学習に使うかどうかはこのページに書かれていない
- 止め方: リクエストごとに `store=false` を渡す（Python の `google-genai` 2.33.0 以降、JavaScript の `@google/genai` 2.31.0 以降など）か、Logs Dashboard の設定でプロジェクト単位でオフにする

- https://ai.google.dev/gemini-api/docs/changelog
- https://ai.google.dev/gemini-api/docs/logs-datasets
