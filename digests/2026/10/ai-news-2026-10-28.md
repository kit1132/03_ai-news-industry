### 1. [新機能] GitHub Copilot の「Assisted permissions」が GA になった — コマンド実行の承認を LLM が肩代わりする選択肢が正式に入った

**要点**: GitHub が10月26日、Copilot のツール実行の許可判定を LLM に任せる Assisted permissions を GA にした。「全部手で承認」か「Allow All」かの二択だったのが、明らかに安全な要求だけ自動で通す中間の選択肢が加わった。管理者は既定モードを決められ、Allow All だけを禁止することもできる。

**詳細**: 一次は GitHub changelog（10/26）。

- 判定の仕組み: コマンド実行・ファイルパスへのアクセス・URL を開く要求を LLM が評価し、「clearly safe」と分類したものは自動で進み、それ以外は利用者の承認を求める
- 対象: Copilot CLI（`/permissions` で assisted を選ぶ）、GitHub Copilot app（モード選択の Tool permissions）、VS Code（権限ピッカー）。対象プランと料金は書かれていない
- 管理者の統制: エンタープライズの管理設定で、Assisted を残したまま Allow All を禁止する、Assisted を個別に無効にする、新規セッションの既定モードを決める、の3つができる。既定モードがポリシーで禁止されている場合は手動承認で始まる

- https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available

### 2. [新機能+仕様] Claude Code 2.1.311 が Bedrock・Vertex・Foundry でモデル設定を外部から読むようになった — クラウド経由の利用でも downloads.claude.ai への通信が発生する

**要点**: Anthropic が10月26日に Claude Code 2.1.311 を出した。Bedrock・Mantle・Vertex・Foundry で使う場合も、モデル設定を downloads.claude.ai の署名付きファイルから読むようになった。「クラウド経由なら Anthropic のホストへ出ない」が前提でなくなり、止めるには環境変数で無効にする必要がある。

**詳細**: 一次は Claude Code の changelog（10/26）。

- モデル設定の読み込み: Bedrock・Mantle・Vertex・Foundry で、モデル設定を downloads.claude.ai の署名付きファイルから取得する。止めるには `CLAUDE_CODE_MODEL_CATALOG=off` を設定する
- VS Code 拡張: VS Code のテレメトリー設定がオフなら、Claude Code のセッションを `DISABLE_TELEMETRY` 付きで起動し、利用指標・エラー報告を送らず、機能フラグも取りに行かない
- `ultrathink`: Opus 5.5・Sonnet 5.5・Haiku 5.5・Fable 5.1 を Anthropic の API で使う場合、そのターンを xhigh の推論レベルで実行する
- 修正: 標準コンテキストのセッションが200Kトークンを超えると「Usage credits required for 1M context」で止まっていた問題を直し、会話を圧縮して続けるようにした。改善16件・修正56件

- https://code.claude.com/docs/en/changelog

- [セキュリティ] Cloudflare Workers AI の GLM-5.3 で他人の会話が応答に混じっていた — Cloudflare が10/26に事後報告を公開した。8/27〜9/9 に、681,280トークンを超えるプロンプトへの応答155件に他の利用者のセッションの文字列が混ざった。原因は KV キャッシュ領域（681,280トークン）とコンテキスト長（1,048,576トークン）の不一致と、SGLang の分離型 prefill/decode で長すぎる要求が中断されないバグの重なり。9/8 に Knostic の研究者が報告し、9/9 に復旧した。意図的な悪用の証拠はなく、利用者側の対応は求めていない。SGLang を自前運用する場合は v0.5.22 以降が推奨。https://blog.cloudflare.com/kv-cache-exposure-remediation/
