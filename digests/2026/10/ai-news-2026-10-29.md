## 今日のハイライト

### 1. [料金+新機能] GitHub Enterprise に Copilot が含まれるようになった — 席の数ではなく予算の消化で管理する形に変わった

**要点**: GitHub が10月28日、営業担当のいる GitHub Enterprise Cloud の契約に Copilot を含めた。席ごとの月次 AI クレジットは付かず、最初の要求から企業の予算に従量で課金される。費用の見積もりは「席数×単価」でなく「予算の消化量」が基準になる。

**詳細**: 一次は GitHub changelog（10/28）。

- 含まれる Copilot: 機能とモデルは Copilot Enterprise と同じ。席ごとの月次 AI クレジットは無く、使用量は最初の要求から企業予算に計上される
- 予算が尽きたとき: コード補完と次の編集候補は動き続ける。Copilot Chat・Copilot code review・クラウドの Copilot は予算が要る。席や予算の要らない機能は止まらない
- Copilot Standalone: GitHub Enterprise ライセンスを持たない利用者向けに **$10/ユーザー/月**
- 既存プラン: Copilot Business・Copilot Enterprise は引き続き買える。セルフサーブ契約は対象外で、日程は「今後数週間」で示す。現行のセルフサーブ契約は変わらない

- https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot

### 2. [料金+新機能] GitHub Copilot Fusion が GA になった — モデルの選択がルーター任せになり、課金も使われたモデルの数で決まる

**要点**: GitHub が10月28日、タスクごとにモデルを振り分けて組み合わせる Copilot Fusion を全プランで GA にした。課金は Fusion が使った各モデルの標準単価の合計で、期間限定で有料プランに30%割引が付く。1回の要求で複数モデル分を払う場合があり、モデル単価だけで費用を試算できなくなった。

**詳細**: 一次は GitHub changelog（10/28）。

- 動き: 努力レベル（Standard・High・Max）を選ぶと、Single（1モデル）・Cascade（速い下書きが品質チェックに落ちたら上位へ）・Critique（別モデルがレビューして修正）の3方式から選ぶ
- 対象: 全 Copilot プランで、VS Code・Copilot app・Copilot CLI・JetBrains。リサーチプレビューの HydraFusion・HydraFusion Max の利用者は対応する努力レベルへ移される
- 管理: 組織・企業のモデルポリシーで有効なモデルだけを使う。Fusion にだけ特定モデルを使わせない設定と、Fusion を既定モデルにする設定ができる
- GitHub の公表値: Artificial Analysis の Coding Agent Index で Fusion Max は60で、Opus 5.5 Max の Claude Code と2ポイント差。1タスクあたりの API 費用とトークンは約半分、所要時間は約40%短い。premium request への影響は書かれていない

- https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion
