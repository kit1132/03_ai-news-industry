## 今日のハイライト

### 1. [料金] ChatGPT Pro・Business の契約に API クレジットが付くようになった — 「ChatGPT 契約」と「API 予算」を別々に見積もる前提が崩れた

**要点**: OpenAI が10月28日、ChatGPT Pro と Business の契約者に月最大 $500 の API クレジットを付けた。Pro は月額と同額、Business は席あたり $20/$100（ワークスペース上限 $500/月）。小規模な API 検証は既存の ChatGPT 契約の範囲で賄えるようになった。

**詳細**: 一次は OpenAI API changelog（10/28）と解説ガイド。

- 付与額: Pro $100 プランは $100/月、Pro $200 は $200/月、Pro $500 は $500/月。Business は Standard 席 $20/月、Premium 席 $100/月で、ワークスペース合算の上限は $500/月（年払いは年 $6,000）
- 使える範囲: Responses API・Agents API（OpenAI ホストのサンドボックス料金を含む）・Decisions API・Realtime API・Images API と、組み込みツールの利用料・保存料。**API キー経由の Codex は対象外**で、ChatGPT やサインイン版 Codex の利用枠も増えない
- 条件: 有効な有料契約で開始から7日以上。ChatGPT 契約と API 組織の両方を本人が所有し、同じメールアドレスであること。Enterprise・Plus・Go・Free は対象外
- 失効: 使い残しは請求サイクルの終わりに失効し、繰り越さない。初回は残り日数で按分

- https://developers.openai.com/api/docs/changelog
- https://developers.openai.com/api/docs/guides/chatgpt-api-credits

### 2. [料金] OpenAI が ChatGPT Pro の Work・Codex 枠を倍にし、Pro 200 の削減を撤回した — 10/30 に予定されていた枠の半減が消えた

**要点**: The Decoder（10/29）によると、OpenAI は Pro 100・Pro 500 の Work・Codex 枠を倍にし、Pro 200 は予定していた削減を撤回した。9/29 の DevDay で決まった「10/30 から Pro 200 の枠を Plus 比20倍→10倍」は前提にできなくなった。

**詳細**: 典拠は OpenAI ヘルプ記事「About ChatGPT Pro tiers」を引く The Decoder（10/29）。ヘルプ記事はオリジン403で本文に到達できず、一次で倍率は確認できていない。

- Pro 100・Pro 500: Work・Codex の枠がそれぞれ従来の2倍
- Pro 200: 低い方の枠（新規契約向け）を2倍にし、利用者の反発を受けて予定の削減を撤回した。Plus は変わらない
- 適用: 新規契約は更新後の枠で始まり、既存契約者にも自動で適用される
- OpenAI の注記: 枠が2倍でも完了できるタスクが2倍になるとは限らない（モデル・タスク・設定で消費が変わる）。Dot は当面広い枠のままで、別枠で集計する
