### 1. [セキュリティ] Cursor の拡張機能マーケットプレイスに Claude Code の偽拡張が約11時間載っていた — 開発者向けマーケットプレイスの拡張は「公式名なら安全」とは言えなくなった

**要点**: The Decoder（10/30）によると、Claude Code を装った悪性拡張が Cursor のマーケットプレイスに木曜（10/29）の約11時間公開され、最大5,000人に影響した可能性がある。Anthropic は開発に関与していない。Cursor 上で Claude Code 拡張を入れた端末は、入手元を確かめる必要が出た。

**詳細**: 典拠は Cursor の説明を引く The Decoder（10/30）。拡張機能名と発見者は記事に書かれていない。

- 収集を試みた情報: ホスト名・ユーザー名・OS・グローバル IP アドレス
- 遠隔操作: 攻撃者が遠隔操作できる設定を試みたが、管理者権限が要るため多くの端末では成立しなかったとみられる
- Cursor の対応: 拡張を削除し、マーケットプレイス全体を一時的に止めた。マルウェアを無効化し、他の拡張に影響がないことを確認してから再開した

- https://the-decoder.com/malicious-claude-code-extension-in-cursors-marketplace-attempted-remote-access-and-data-theft/

### 2. [破壊的変更+新機能] Claude Code 2.1.314 で作業ディレクトリ外への書き込みを全モードで止められるようになった — 権限モードに頼らずに書き込み範囲を設定で固定できる

**要点**: Anthropic が10/30に出した Claude Code 2.1.314 に `permissions.blockWritesOutsideWorkingDirectories` が入った。有効にすると Write・Edit・NotebookEdit は、どの権限モードでも作業ディレクトリ外のパスを拒否する。auto mode を許す運用でも、書き込み範囲は設定側で固定できるようになった。

**詳細**: 一次は Claude Code changelog（2.1.314・10/30）。前回確認の 2.1.312（10/27）から 2.1.313 は欠番で、本版が最新。

- Claude apps gateway: 上流ごとに `groups`（IdP グループ）を指定でき、フェイルオーバー時も対象外の開発者は送られない。Bedrock 上流には、発火したガードレールを記録する `guardrail_trace` が加わった
- アイドル時の圧縮: VS Code と Claude Desktop の Code タブで、20万トークン超の会話を放置すると要約する。テレメトリーを切った契約者や、Bedrock・Vertex・Foundry・LLM ゲートウェイでも1時間キャッシュ有効時に動く
- 管理者による effort 上限: 上限を超える effort で毎ターン失敗していた不具合を直し、effort を下げて再試行するようにした

- https://code.claude.com/docs/en/changelog
