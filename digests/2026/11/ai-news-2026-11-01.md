## 今日のハイライト

### 1. [廃止] Claude Opus 4.8 の fast mode が11/30に削除される — 高速出力を使い続けるには Opus 5.5 への移行が前提になった

**要点**: Anthropic が10/30、Claude Opus 4.8 の fast mode を非推奨にし、11/30に削除すると告知した。削除後に `claude-opus-4-8` へ `speed: "fast"` を送るとエラーになり、通常速度の Opus 4.8 には切り替わらない。fast mode を組み込んだ処理は、29日以内に Opus 5.5 へ移す必要が出た。

**詳細**: 一次は Claude Platform のリリースノート（10/30）。Claude Code 2.1.316（10/31）の changelog にも同じ告知が載った。

- 料金: fast mode の単価は Opus 5.5 が入力 $8・出力 $40、Opus 5 と Opus 4.8 が $10・$50（100万トークンあたり）。移行すると単価は2割下がる
- 提供範囲: Opus 5 と Opus 4.8 の fast mode は research preview。Google Cloud（Anthropic managed）と Microsoft Foundry（Azure ホスト）で使えるのは Opus 5.5 だけ
- 移行先: リリースノートは Opus 5.5 の移行ガイド（Opus 4.8 からの移行節）を案内している

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/about-claude/pricing

### 2. [破壊的変更] OpenAI が Daybreak Blue のセッションデータを11/29から学習に使う — 「学習に使わない」設定でも対象になる

**要点**: The Decoder（10/31）によると、OpenAI は Trusted Access プログラムの参加者に、Daybreak Blue のサイバーセキュリティ作業データを11/29から学習に使うとメールで伝えた。これまでは「モデル改善」の設定をオフにしていれば学習から外れていた。脆弱性診断の作業内容も学習に回る前提に変わった。

**詳細**: 典拠は The Decoder（10/31）と、記事が引く参加者向けメール。OpenAI の一次ページでは確認できていない。

- 除外方法: 反発を受けて2通目のメールが送られ、別の除外（オプトアウト）手段を約束した。手順は記事に書かれていない
- 例外: 安全性審査で検知されたやり取りは、従来どおり安全目的で使われる

- https://the-decoder.com/openai-plans-to-train-models-on-daybreak-blue-cybersecurity-session-data-that-was-previously-off-limits/

### 3. [新機能] Claude Code 2.1.316 でグループ共有の月間予算を組めるようになった — チーム単位の支出上限を gateway 側で固定できる

**要点**: Anthropic が10/31に出した Claude Code 2.1.316 で、Claude apps gateway に `pooled_budget` が入った。グループのメンバーが共有する月間予算を、各メンバーの上限に重ねて設定できる。メンバー別の上限だけでなく、チーム全体の支出も上限で止められるようになった。

**詳細**: 一次は Claude Code changelog（2.1.316・10/31）。前回確認の 2.1.314（10/30）から 2.1.315 は欠番。

- サブエージェントの effort: `CLAUDE_CODE_SUBAGENT_EFFORT` でサブエージェントの effort を個別に決められる。従来はセッションの値を引き継いでいた
- 管理ポリシー: `managed.policy_mode: layered` にすると、該当するポリシーをすべて重ねて適用する。従来は最初に一致した1つだけだった
- 管理設定の配布: Team・Enterprise で Anthropic の API から取得した管理設定は、承認プロンプトなしで適用される。検証できない保存済みのコピーは拒否される

- https://code.claude.com/docs/en/changelog
