### 1. [新機能+仕様] Copilot の PR 承認が必須レビュー数に数えられるようになった — 最上位の Max レビューもプレビュー公開

**要点**: GitHub は Copilot code review に PR の承認機能を一般提供（GA）し、有効にすると Copilot の承認がリポジトリの必須承認数に数えられる。これまで「AI レビューは参考意見で、承認は人が出す」前提だったブランチ保護の設計が、組織の設定しだいで変わる。

**詳細**: GitHub changelog（10/28）。10-29 は Universe 関連の changelog を個別に確認できず見送っており、本日 Publickey（11/3）経由ではじめて内容を確認した。

- 承認: 既定はオフ。Enterprise・Organization・リポジトリ単位で有効にでき、リポジトリ管理者は Copilot が承認してよいファイルパスを絞れる。新しいコミットが push されると人の承認と同じく取り消される
- Max: Lite・Balanced の上に加わった3段目のレビュー段階で、パブリックプレビュー。提供元の異なる複数モデルのレビューエージェントを独立に走らせ、集約エージェントが結果を突き合わせる。時間がかかり、AI クレジットの消費も Lite・Balanced より多い（倍率は非公表）
- 管理: 管理者はレビュー段階の上限を設定でき、上限を超える段階は選べなくなる
- 対象プラン: Copilot Pro・Pro+・Max・Business・Enterprise

- https://www.publickey1.jp/blog/26/githubcopilot_code_review_maxgithub_universe_2026.html
