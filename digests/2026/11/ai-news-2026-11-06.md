### 2. [廃止+新機能] OpenAI が GPT-6-Cyber を出し、gpt-5.5-cyber-preview は2027年2月1日に API から削除 — 入力 $20・出力 $100

**要点**: OpenAI は 11/5、脆弱性の調査・再現・修正確認に使う GPT-6-Cyber を API に追加し、同じ日に前のモデル `gpt-5.5-cyber-preview` の廃止を告知した。後継の単価は入力 $20・出力 $100（100万トークンあたり）で、Daybreak Red の承認を受けた組織しか使えない。前のモデルを使う組織は、承認を取り直してから移ることになる。

**詳細**: changelog（11/5）、廃止ページ（2026-11-05 付）、モデルページで確認した。

- 単価: 入力 $20、キャッシュ入力 $2、キャッシュ書き込み $25（30分。12時間は $50）、出力 $100。いずれも短いコンテキストの価格
- 仕様: コンテキスト 1,050,000、入力上限 922,000、出力上限 128,000 トークン。Responses と Chat Completions で使え、Batch は使えない
- 利用条件: Daybreak Red へのアクセスと承認が必要で、可否はアカウント担当が確認する
- 廃止: `gpt-5.5-cyber-preview` は2027年2月1日に削除される。移行先は「使える範囲で最も高性能なサイバーモデル」とだけ書かれている

- https://developers.openai.com/api/docs/deprecations

### 3. [セキュリティ+新機能] Claude の組織に IP 許可リストを設定できる（ベータ） — Enterprise では Claude Code も社外ネットワークから使えなくなる

**要点**: Anthropic は 11/5、Claude Console と Claude Enterprise の組織で、接続元の IP アドレスを限定できる許可リストをベータで出した。API キーやサインインが漏れても、登録した外のネットワークからは使えない。Enterprise で有効にすると、Claude Code・Office アドイン・Cowork も社外の Wi-Fi やモバイル回線から使えなくなる。

**詳細**: リリースノート（11/5）と設定ページで確認した。料金の記載はない。

- 登録: IPv4・IPv6 の単一アドレスか CIDR（IPv4 は /8、IPv6 は /32 より狭い範囲）で、1組織1,000件まで。反映に最大15分かかる
- API 側の対象: Messages・Batches・Token Counting・Models・Files・Skills、Managed Agents のエンドポイント、Admin API・Compliance API。Bedrock・Google Cloud・Microsoft Foundry 経由の Claude には掛からない
- Enterprise 側の対象外: Claude Design、Claude in Slack、Claude Academy。締め出されたユーザーの実行中タスクは最大24時間続く
- 同じ日の追加: Admin API の `POST /v1/organizations/users/{user_id}/sign_out`（ベータ）で、Enterprise のメンバーをすべての端末から一括サインアウトできる

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/manage-claude/ip-allowlist
