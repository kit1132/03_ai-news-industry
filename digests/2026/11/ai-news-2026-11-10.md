**要点**: Anthropic が 11/9 に Fable 5.2 を公開し、単価を入力 $8・出力 $40 と Fable 5.1 比20%下げた。最上位モデルで組んだ費用試算は引き直しになる。移行時に 400 エラーになる破壊的変更が4つある。

**詳細**: Anthropic のリリースノート・料金ページ・「What's new in Claude Fable 5.2」（いずれも 11/9）を一次で確認した。

- 単価: キャッシュヒット $0.20（入力の0.025倍）、Batch $4/$20、fast mode $16/$80。fast mode は出力速度が最大2.5倍になり、beta ヘッダーは要らない
- 仕様: コンテキスト1M、最大出力128k、adaptive thinking は常時オン。Claude API・Claude Platform on AWS・Bedrock・Google Cloud・Microsoft Foundry で使える。30日のデータ保持が必須で、ZDR では使えない
- Claude Mythos 5.2: 能力は同じで単価も同じ。使えるのは Cyber Verification Program などで審査を通った組織だけ
- 破壊的変更: ①prefix check がすべてのアカウントに掛かる（`system`・`tools`・前のメッセージを書き換えて thinking ブロックを返すと 400）、②Fable 5.2 の thinking ブロックを読めるのは Fable 5.2・Mythos 5.2 だけ、③`computer_20251124` は Bedrock 以外で 400、④advisor tool では advisor に Fable 5.2・Mythos 5.2 しか指定できない。Claude Code・claude.ai・Managed Agents・Agent SDK 経由なら影響はない
- 退役: Fable 5.1・Mythos 5.1 は Active のままで、退役下限は 2027/9/1。Fable 5.2 の下限は 2027/11/9

### 2. [セキュリティ] Claude Code の「次回から表示しない」で秘密情報が GitHub に 2,539件公開されていた — 修正はまだ出ていない

**要点**: Apiiro が、Claude Code の「次回から表示しない」でパスワード入りのコマンドが設定ファイルに残り、公開リポジトリから秘密情報 2,539件が見つかったと公表した。Anthropic の修正はまだ無い。

**詳細**: GIGAZINE（11/9）の記事を WebFetch で確認した。Apiiro の一次は未確認。

- 規模: GitHub 上の `.claude/settings.local.json` 104,185件のうち1,122件から1,379件（API トークン398件・DB パスワード379件など）。Git 履歴・共有設定・会話記録からさらに1,160件見つかり、63組織に関わる情報も含まれていた
- 検出の難しさ: 1,122件のうち215件は、2種類のスキャナのどちらでも検出されなかった。8KB 以上の設定ファイルでは9.9%に秘密情報があった
- 対応: Claude Code 責任者の Boris Cherny 氏が 11/7 に Hacker News で、認証情報の検出や auto mode で保存を防ぐ方法など複数案を試作中だと書いた。`.gitignore` は端末ごとの設定なので、一度コミットしたファイルは守れない
- Apiiro の推奨: 公開されていないか確認する、パスワードは環境変数で渡す、漏れた認証情報は失効させて再発行する

- https://gigazine.net/news/20261109-claude-code-leak-secrets/
