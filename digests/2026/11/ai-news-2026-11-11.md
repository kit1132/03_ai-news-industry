### 3. [破壊的変更+予定] GitHub が 12/8 から1年間動きの無いリポジトリの Dependabot アラートを止める — 放置リポジトリの脆弱性通知が自動で消える

**要点**: GitHub が 12/8 から、過去1年に push の無いリポジトリの Dependabot アラートを停止する。既存のアラートは削除ではなくアーカイブになる。保守だけ続けている社内リポジトリでも、何もしないと脆弱性の通知が来なくなる。

**詳細**: GitHub changelog（11/10）を一次で確認した。

- 活動の定義: いずれかのブランチ・タグへの push、リポジトリの作成、Dependabot アラートの有効化
- 対象外: Dependabot アラートを有効にするセキュリティ設定を強制しているリポジトリと、アラートの切り替えを Enterprise のポリシーで禁じているリポジトリ。GitHub Enterprise Server も対象外
- 再開: push すれば自動で戻り、設定画面からも戻せる。どちらでも1年の計測はやり直しになる。Dependabot のセキュリティアップデートへの影響は書かれていない

- https://github.blog/changelog/2026-11-10-dependabot-alerts-will-pause-on-inactive-repositories
