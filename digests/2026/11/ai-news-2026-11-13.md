### 1. [料金] Google の Gemini 4 Hydrogen が $1.50/$7.50 で上位の Argon を上回った — 12/1 に倍額になる Argon を前提にした試算は引き直しになる

**要点**: Google が Gemini 4 Hydrogen を Gemini 3.8 Flash の後継として出した。単価は入力 $1.50・出力 $7.50 で、AA Index でも上位の Argon を上回った。Argon は 12/1 に $4/$20 へ倍額になるため、Argon を前提にした費用の試算は Hydrogen で引き直すことになる。

**詳細**: The Decoder（11/12）で確認した。Google の一次（`aistudio.google.com`）には届かなかった。

- 単価: 入力 $1.50・出力 $7.50・キャッシュヒット $0.075（いずれも 100万トークンあたり）。コンテキストは入力・出力とも最大 1M
- 性能（Hydrogen 対 Argon）: AA Intelligence Index 51 対 50（xhigh は 54）、SWE-sweep 13.5% 対 4.3%、OSWorld-2.1 77.6% 対 74.7%。Chartography だけは Argon が上（71.6% 対 66.6%）
- 提供先: Gemini API（AI Studio）、Gemini アプリ、Google 検索、Antigravity（Pro・Ultra）、Gemini for Business。Vertex AI と GitHub Copilot には記事で触れていない
- Argon の値上げ: 導入価格は 11/30 に終わり、12/1 から $4/$20 になる（記録済み）

- https://the-decoder.com/googles-gemini-4-hydrogen-outscores-the-bigger-argon-just-four-weeks-after-its-launch/

### 2. [新機能] Anthropic が Claude Managed Agents のサービス本体を自社環境で動かせるようにした — セッション履歴を社外に置かない構成が選べるようになった

**要点**: Anthropic が Managed Agents の API・エージェントループ・保存領域を自社のクラウドやデータセンターで動かせる版を出した。これまで自社に置けたのはサンドボックスだけで、セッション履歴は Anthropic 側に残っていた。推論先も Bedrock・Google Cloud・Foundry・自前ゲートウェイから選べる。

**詳細**: Anthropic のリリースノート（11/12）とドキュメントで一次確認した。利用にはアカウント担当への申請が要る。

- 構成: サーバー `cma-server`（API・エージェントループ・保存）と PostgreSQL 16 以降、ツールを実行するワーカー。DB を置かないとデータはメモリだけに残り、再起動で消える
- 社外に出るもの: モデル呼び出しごとの会話内容（ツールの入出力を含む）。Claude API に送る場合はセッション・エージェント・環境の ID も付く
- 自社の責任: サーバーの保護、メモリストアの運用、不審な利用の検知、リリースごとの更新。`bash` ツールはワーカーの権限で動く本物のシェルで、隔離は実行するコンテナや VM で確保する
- 制約: 一部の機能はホスト版にしか無い（「Differences from the hosted service」に一覧）。信頼レベルごとに別のデプロイが要る

- https://platform.claude.com/docs/en/release-notes/overview
- https://platform.claude.com/docs/en/managed-agents/self-hosted
