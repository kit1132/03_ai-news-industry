### 2. [破壊的変更+新機能] Claude Code 2.1.323 が未知のモデルのコンテキストを 1M とみなすようになった — 他社モデルで使うとセッションが毎ターン失敗しうる

**要点**: Anthropic が Claude Code 2.1.323（11/12）で、認識できないモデル ID のコンテキスト長の既定を 200K から 1M に変えた。窓の小さい他社モデルでは満杯後に毎ターン失敗しうるため、サードパーティのモデルで使う構成は `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` の設定が前提になった。

**詳細**: Claude Code の changelog で一次確認した。

- 既定の変更: 未知のモデル ID は 1M とみなす。早めに圧縮するなら `/autocompact`、200K に戻すなら `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`
- MCP: v1 の MCP クライアントを削除した。`MCP_SDK_GENERATION=v1` は v2 クライアントの互換モードで動く。MCP サーバーのサインインを完了させる操作は bypass・auto モードでも確認を求める
- 新機能: Code Mode（実験的・オプトイン）。Claude がツールを呼ぶ JavaScript を書く方式で、組織単位で無効にもできる
- 権限まわり: `/security-review` は実行前に確認を求める。Claude Code 内部の ripgrep と git コマンドの多くはサインイントークンや API キーを渡さずに動く

- https://code.claude.com/docs/en/changelog

**詳細**: GitHub changelog（11/13）で一次確認した。前日のダイジェストで「Copilot での提供は記事に記載なし」としていた点が解けた。

- 対象: VS Code・Visual Studio・JetBrains・Xcode・Eclipse・Copilot CLI・coding agent・Copilot app・github.com・GitHub Mobile・Copilot SDK
