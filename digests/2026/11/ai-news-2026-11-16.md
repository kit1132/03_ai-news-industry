### 1. [新機能] ChatGPT Enterprise を AWS Marketplace で買えるようになった — AWS のコミット消化に充てられ、調達の経路が AWS 契約の中に入った

**要点**: OpenAI が 11/9 に ChatGPT Enterprise を AWS Marketplace で提供し始めた。対象となる支出は AWS のコミットに算入できるため、AWS と大口契約を持つ企業では、ChatGPT の導入が新規ベンダーとの契約から既存の AWS 予算の使い道の1つに変わった。

**詳細**: TLDR AI の週次スイープ（11/10号）で、7日遅れで検知した。一次（`openai.com`）はオリジン403のため、複数の二次報道で突き合わせた。

- 対象: Chat・ChatGPT Work・Codex・dots の一式。ChatGPT for Healthcare・for Financial Services も対象の顧客に提供する。機能は OpenAI と直接契約した場合と同じとしている
- 価格: プライベートオファーで個別に決める。定価は公表されていない
- コミット算入: 対象の支出が算入できるが、顧客と AWS の契約条件による
- 留保: AWS 経由で買ってもデータが AWS 上に留まる保証はない（データ処理者は OpenAI のまま）。ChatGPT 内のクレジット消費が AWS の請求にどう反映されるかは説明されていない

- https://openai.com/index/chatgpt-enterprise-aws-marketplace/
- https://ppc.land/aws-customers-can-now-buy-chatgpt-enterprise-against-cloud-commitments/

## 開発ツール・モデル

- [新機能] Cloudflare が AI エージェント専用のヘッドレスブラウザ Kitesurf をオープンソース化した — Publickey（11/16）によると、ライセンスは Apache 2.0（Cloudflare の告知は 11/13）。タブ・拡張機能などの人間向け機能を省き、Chromium と比べて CPU とメモリの効率が3〜7倍としている。主に Rust で書かれ、WebAssembly にコンパイルして Cloudflare Workers 上で動く。CDP に対応するため Puppeteer などから接続できる。https://www.publickey1.jp/blog/26/cloudflareaikitesurf.html
- [新機能] Meituan が 1.6兆パラメータのエージェント型モデル LongCat-2.5 を MIT ライセンスで公開した — The Decoder（11/15）によると、アクティブパラメータは約480億。自社評価では Terminal Bench v2.1 が 88.4（Claude Opus 5 は 89.1）、BrowseComp が 91.9 だった。API は OpenAI・Anthropic 両形式に対応し、期間限定価格は入力 €0.27・出力 €1.07（100万トークンあたり）。学習は中国製ハードウェアだけで行い、Nvidia の GPU は使っていないという。https://the-decoder.com/meituan-releases-a-1-6-trillion-parameter-agent-model-that-never-touched-an-nvidia-gpu/
- [新機能] Google Antigravity に複数のエージェントを並列で動かす `/swarm` が加わった — TLDR AI（11/11号）で検知した。名前付きのエージェントがタスクを分担し、共有のメッセージボードで調整する。Google AI Pro・Ultra で App と CLI の両方から使える。ワーカーごとに別のエージェントとして動くため、クォータの消費は単一の会話より速い。https://antigravity.google/docs/swarm/
- [新機能] OpenAI が ChatGPT 専用の機能を MCP サーバーに足す MCP Extensions をオープンソースで公開した — TLDR AI（11/12号）で検知した。TypeScript と Python のパッケージで、サイドバーの入口・独自のファイルビューアなどを追加できる。https://github.com/openai/mcp-extensions
- [動向] PostgreSQL 19 のリリースが 11/19 にずれ込み、LLM によるコードレビューで見つかった不具合が一因とされた — Publickey（11/15）によると、β4 で SQL/PGQ など6項目が取り下げ・削除された。コミッターの Peter Eisentraut 氏は、LLM 支援のレビューで約40件の不具合報告が短期間に集まったと述べている。例年は9〜10月にリリースされていた。https://www.publickey1.jp/blog/26/postgresql_194ai.html
- [据え置き] Anthropic・OpenAI・xAI の料金・廃止ページと Claude Code の changelog に新しい告知なし — Anthropic のリリースノートは 11/12、廃止履歴は 9/30 のまま。Claude Code は 2.1.325（11/13）が最新。OpenAI の changelog は 11/5、廃止ページは 11/10 付が最新。xAI は grok-4.7 が最新。GitHub changelog も 11/13 から更新がない。https://platform.claude.com/docs/en/release-notes/overview
