### 1. [破壊的変更+料金] OpenAI が GPT-6.2 Astra・Sol を出し、Astra の単価を 20% 下げた — 上位モデルの基準単価が $10/$50 から $8/$40 に変わった

**要点**: OpenAI が 11/17、API に GPT-6.2 Astra と GPT-6.2 Sol を加えた。Astra の Standard 単価は GPT-6 Astra の $10/$50 から $8/$40 に下がり、キャッシュ入力は $1.00 から $0.40 になった。Sol は GPT-6.1 Sol と同じ $2/$10 のまま。上位モデルで試算する場合、単価の前提は $8/$40 に置き換わる。

**詳細**: 一次（developers.openai.com の changelog・料金ページ）で確認した。単価は100万トークンあたり。

- `gpt-6.2-astra`: 入力 $8.00・出力 $40.00・キャッシュ $0.40。Batch・Flex は半額の $4/$20
- `gpt-6.2-sol`: 入力 $2.00・出力 $10.00・キャッシュ $0.10（GPT-6.1 Sol と同額）
- バックグラウンド処理の完了期限（Responses API・パブリックベータ）: 2時間を選ぶと Standard より 30% 安く、8時間を選ぶと 40% 安い。対象は 6.2 Astra・6.2 Sol・6.1 Terra・6 Luna
- Ultrafast: 6.2 の2モデルは 2027-02-28 まで Standard の3倍、2027-03-01 から6倍になる
- ChatGPT Work と Codex では Plus・Pro・Enterprise・Edu に同日提供した。Unite.ai によると、Astra は OpenAI が外部に出したモデルで初めて自己改善能力の評価が High になった

### 2. [料金+新機能] Microsoft が GitHub Copilot に MAI Code 2 を出した — 単価は 2027年5月16日までの導入価格で、その翌日から倍になる

**要点**: Microsoft が Ignite 初日の 11/17、自社のコーディングモデル MAI Code 2 と MAI Code 2 Flash を GitHub Copilot で一般提供した。MAI Code 2 の単価は入力 $0.50・出力 $2.50 だが、これは 2027-05-17 までの導入価格で、それ以降は $1.00/$5.00 になる。Business・Enterprise では管理者が止めない限り自動で有効になる。

**詳細**: GitHub の changelog とモデル料金表（一次）で確認した。単価は100万トークンあたりで、Copilot の従量課金に計上される。

- MAI Code 2: 入力 $0.50・キャッシュ $0.025・出力 $2.50。2027-05-17 から $1.00・$0.05・$5.00。対象は Pro・Pro+・Max・Business・Enterprise
- MAI Code 2 Flash: 入力 $0.05・キャッシュ $0.005・出力 $0.25。2027-05-17 から入力 $0.10・キャッシュ $0.01。Free・Student も含む全プランが対象
- 既定の有効化: 新モデルを自動で有効にする設定のままだと、2モデルとも使える状態になる。止めるには Copilot 設定のモデルポリシーで個別に無効にする
- Microsoft は、MAI Code 2 が GPT-6.1 Sol のコーディング性能の 98% を 40% の価格で出すと説明した（二次報道。40% は導入価格での比較）
- 同日の Copilot Fusion の更新で、Fusion Standard に MAI-Code-2、Fusion Max に Claude Sonnet 5.5、Fusion High に GPT-6.1 Terra が加わった

### 3. [破壊的変更+セキュリティ] Claude Code 2.1.326 は組織のポリシーを読み込めないとき auto mode で始まる — 手動承認が既定だという前提が崩れた

**要点**: Claude Code 2.1.326（11/16）で、モードを指定していないターミナル・VS Code のセッションが、組織ポリシーの読み込み前には Manual ではなく auto mode で始まるようになった。フックの `"decision": "block"` が効く場面も広がり、常に block を返すフックは呼び出しを止め始める可能性がある。

**詳細**: 一次（code.claude.com の changelog）で確認した。

- auto mode が既定になる範囲: モード未指定でポリシー未読込のセッションと、Claude Code + Cowork の HIPAA 構成の組織。後者は `disableAutoMode` で止められる
- フック: `"decision": "block"` が保たれる場面が増えた
- そのほか: auto mode が以前は通していたシェルコマンドの一部を止めるようになり、macOS では一部の Bash コマンドで確認や拒否が増えた
- 追加: `/status` に、プロバイダーや `DISABLE_TELEMETRY` などで無効になっている機能を示す行が加わった。`OTEL_RESOURCE_INCLUDE_HOST` で OpenTelemetry に `host.name`・`host.id` を含められるようになった（既定はオフ）

- https://code.claude.com/docs/en/changelog
