### 2. [破壊的変更+新機能] Claude Code 2.1.328 が他社クラウド上の Opus 4.6・Sonnet 4.6 でも auto mode を既定にした — Bedrock・Vertex・Foundry の対話セッションの既定動作が変わる

**要点**: Claude Code 2.1.328（11/19）で、Amazon Bedrock・Google Cloud・Microsoft Foundry 上の Opus 4.6・Sonnet 4.6 でも auto mode が使えるようになった。権限モードを指定しない対話セッションは auto mode で始まる。他社クラウド経由でも、確認なしで進む操作が増える。

**詳細**: 一次（code.claude.com の changelog）で確認した。2.1.327 が予告した「課金付き分類フォールバックの削除」は、2.1.328 の変更点には書かれていない。

- auto mode の既定化: 対象は Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude apps gateway。他社クラウド上の plan mode と Bash の確認画面も auto mode を勧めるようになった。止めるには `disableAutoMode` を使う
- フックの挙動変更: Code Mode はスクリプトの出力に UserPromptSubmit フック（管理者が配布したものを含む）を実行しなくなった。出力を伏せるには PostToolUse フックの `updatedToolOutput` を使う。管理者配布の `PostToolUse` フックは、実行前に拒否された呼び出しでは発火しなくなった
- `mcp_tool` フック: `"onFailure": "block"` を追加した。フック自体の呼び出しに失敗したら操作を止める
- `/code-review`: 多くのモデルで、バグと CLAUDE.md 違反だけを報告するようになった。各指摘に Important・Pre-existing・Nit の区分を付ける。整理系の指摘は `/simplify` に移った
- sandbox: 起動できないときは、次の sandbox 内 Bash コマンドを拒否し、セッション中 sandbox が無効だと伝える（`sandbox.failIfUnavailable` 未設定時）

- https://code.claude.com/docs/en/changelog
