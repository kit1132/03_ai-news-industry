### 1. [料金+予定] ChatGPT のサイト公開機能 Sites が 2027年2月1日から課金される — 無料で置けたサイトが、月のクレジット枠を超えると有料になる

**要点**: OpenAI が Sites（ChatGPT で作ったサイトやアプリを公開する機能）の料金を公開した。ホスティングは 2027年1月31日まで無料で、2月1日から Plus・Pro・Business の月間枠を超えた分が課金される。データベースを持つサイトは空でも1件ごとに枠を使うため、無料で置いてきた社内ツールは件数の棚卸しが必要になる。

**詳細**: OpenAI の Sites の料金ページによる。利用量は 2027年1月1日からアプリ上に表示される。

- 月間枠（利用者のサイト全体で共有）: Plus 125 クレジット、Pro 375、Business は1席あたり 125。Enterprise は契約したクレジットから引かれ、ドル建ての契約なら Codex のトークンと同じ契約額から別単価で引かれる
- 消費の目安: ストレージなしのサイトは 0。ストレージありのサイト（空のデータベースを含む）は1件につき月 25、通信 10万リクエストごとに 15、データベース保存 1GiB・月ごとに 150、ファイル保存 1GiB・月ごとに 3.75、独自ドメインは1件につき月 25（取得費は別）
- Enterprise のみ: サイトとトンネルの接続は 30日ごとに 125（日割り）
- 枠を超えたときの扱いと、Edu の枠は書かれていない

- https://learn.chatgpt.com/codex/sites/usage-and-cost
- https://learn.chatgpt.com/docs/sites

### 2. [破壊的変更+新機能] Claude Code 2.1.332 が Foundry の既定モデルを Sonnet 5.5 に変えた — デプロイしていない組織は設定を直すまで起動時のモデルが使えない

**要点**: Claude Code 2.1.332（11/25）で、Microsoft Foundry の既定モデルが Sonnet 5.5 に替わった。`claude-sonnet-5-5` をデプロイするか、環境変数で使えるモデルを指定する必要がある。クラウド経由の既定モード、テレメトリの名前、トークンの形式も同時に変わった。

**詳細**: Claude Code changelog（11/25）による。

- Foundry: 既定モデルが Sonnet 5.5 に、`opus` の別名が Opus 5.5 に替わった。`claude-sonnet-5-5` をデプロイするか、`ANTHROPIC_DEFAULT_SONNET_MODEL` にデプロイ済みのモデルを設定する。Sonnet 4・Opus 4・Opus 4.1 は退役済みの扱いになった
- 既定モード: Bedrock Mantle・Google Cloud の Agent Platform・Foundry で Sonnet 5／5.5 に移ったセッションは、モード未設定なら auto mode で始まる。止めるには `disableAutoMode` を `"disable"` にする
- Bedrock Mantle: `sonnet` の別名が誤って Haiku 4.5 を指していたのを Sonnet 5 に直した。Sonnet 5 を有効にしていないアカウントではエラーになる
- テレメトリ: デスクトップの Code タブの OpenTelemetry `service.name` が `claude-code-desktop` になった。`claude-code` で絞り込んでいる集計は直すか、`OTEL_SERVICE_NAME` で旧名を指定する
- セルフホストランナー: `CLAUDE_CODE_OAUTH_TOKEN` の接頭辞に `oat02-` が加わった。`oat01-` で照合するプロキシ規則やログのマスクは直す必要がある
- 新機能: MCP サーバーのスキルを `server:skill` の名前で使えるようになり（ベータ）、スキルの埋め込みシェルコマンドを拒否できる `PreSkillShellCommand` フックが加わった

- https://code.claude.com/docs/en/changelog
