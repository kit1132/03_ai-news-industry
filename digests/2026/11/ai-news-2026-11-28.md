## 今日のハイライト

### 1. [破壊的変更+料金] Google Workspace は AI エージェントに REST API を使わせない — 2027年2月1日から MCP サーバーか CLI 経由が必須、4月1日から利用枠の課金が始まる

**要点**: Google は Workspace の AI 利用規約の追加条項で、AI エージェントが Gmail・Drive などにアクセスする経路を MCP サーバーと Workspace CLI に限った。2027年2月1日から技術的に強制する。自前の REST API 連携で組んだエージェントは、この日までに作り直す必要がある。

**詳細**: Google Cloud ブログ（11/25）による。11-26 に収録した Workspace MCP サーバー・CLI の正式版化と同じ発表で、移行期限は今回一次で確認した。

- 対象の MCP サーバー: Gmail・Drive・Docs・Sheets・Slides・Calendar・Chat・Tasks の8つ。MCP サーバーはエージェント以外の OAuth クライアントを受け付けない
- エージェントの識別: Workspace に接続するエージェントは専用の OAuth クライアント ID を使う。利用枠（usage quotas）の課金は 2027年4月1日に始まる。単価はブログに書かれていない
- 人の承認: メール送信・Drive の共有権限の変更・一括編集の前に、利用者の明示的な確認を求める
- 影響しないもの: AI を使わない従来のアプリは REST API のまま動く
- GIGAZINE（11/27）は、2月1日以降に REST API へ直接アクセスするエージェントの利用上限が、有料プランでも無料プランと同じ水準になると報じた。ブログ本文にこの記述は無く、出典の開発者ドキュメント（`developers.google.com`）には到達できなかった
- Gmail MCP の送信・返信・下書き編集がパートナー限定と書かれていた注記は、GIGAZINE によると 11/27 に開発者ドキュメントから削除された（11-27 に見送った指摘の続報）
